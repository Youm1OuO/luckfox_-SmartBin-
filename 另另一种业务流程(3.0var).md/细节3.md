# 疑似新物品 D：局部出现、完全遮挡、放下后完整露出的处理

新物品 D 第一次被看到时，YOLO 通常只能看到被手遮挡后的一个小框。这个框不是完整物品框，不能把它当成库存物品的 `A.box`，
也不能只依赖“初始小框 + 手位移” 得到一个精确可靠的完整物品估计框。

D 仍然要和【被手部分遮挡】物品一样逐帧维护：保存首次/最近局部框、自己的`move_values`、候选 `track`、公共手轨迹起点，以及 `hold_and_move` 和证据计数。
手还在但 D 暂时完全看不见时，只继续追加手位移和候选路径；这属于模糊帧，不能增加或清零证据，也不能删除 D。

但 D 与已有库存物品 C 有一个必要差别：D 的首次小框不是“原来的货架位置”。因此“初始位置看不到 D”对 D 不是正向移动证据，也不能用于判断 D 是否被拿走。
D 不会产生 OUT；若最终没有后续证据，只清理这次疑似 D。

当手离开后第一次看到一个未被已有库存认领的同类完整检测框 B 时，不能只拿 B 与 D 的首次小框做严格/局部匹配。
应把 B 与 D 的整条候选 `track` 比较，并允许“完整 B 覆盖或包含预测的局部 D 框”、或与该路径段足够接近的局部→完整重现匹配。

只有同时满足以下条件，才把 B 认作 D 的重新露出：

1. D 曾在已处理的有手帧中贴手出现，且当时无法认领给已有库存；
2. B 与 D 类别相同，且不能严格认领给任何已有库存物品；
3. B 在 D 的候选路径上存在唯一合理匹配；若同类候选或多个 D 都同样合理，则保持未决；
4. B 在后续无手稳定快照中继续存在。

满足前 3 条时，B 是 D 的第二条身份/放下证据，可把 D 提升到工作库存并记录 `placed_box`；第 4 条成立后才正式产生 IN。
D 是否已经凑够两次 `hold_and_move` 正向证据不是入库的前提：现实中 D 可能一直被手完全遮挡，直到手离开后才第一次
完整露出。

## 与已有 HAND_PARTIAL 物品 C 的共同点和差别

已有库存物品 C 也可能先部分露出、随后被手完全挡住。
只要手还在，C 的旧位置和估计位置都找不到 C 时同样属于模糊帧：`hold_evidence_count` 与 `not_hold_evidence_count` 都不增加、不清零，C 保持 HAND_* 和候选 `track`，不能因为连续看不见就恢复为【可见】。
若手对 C 的完整估计框覆盖率达到 e1，则 C 可从 HAND_PARTIAL 转为 HAND_FULL；是否有 C 的 YOLO 框不改变这一点。
但 C 已经有可靠完整的 `C.box`，因此手离开后应优先用“完整 `C.box` + 整条候选 `track`”寻找重新露出的完整 C。
D 才需要本文件定义的“局部预测框 → 完整 B”专用匹配。
C 的完整路径无法唯一匹配时，应保持未决并在无手稳定收尾中继续用完整框和整条路径复查；不要用 C 的局部小框作为身份兜底，否则同类物品容易串身份。
