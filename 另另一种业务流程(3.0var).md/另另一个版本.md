> IoM(A, B) = 面积(A ∩ B) / min(面积(A), 面积(B))

4. [框宽的差值]是否足够小       <!-- [框高的差值、框宽的差值]这两个都小, 说明两个框的大小形状越接近 -->

**说明**
> 这个版本直接用每张 Yolo 输出的作为[快照]
> 库存的更新是: [当前快照]与[库存]进行比较的
> track的更新是: [当前快照]与[前一张快照]进行比较的 (当然也会用到库存的信息)

为了实现这个方法, 库存物品中要增加一些状体, 现在的状态有:【可见】、【遮挡】、【被手部分遮挡】、【被手完全遮挡】
其中:
    【遮挡】的物品其实还在原来的位置的, 只不过他现在看不见了而已(被其他物品挡住了)
    【整理中】的物品不在原来的位置了, 现在他去了其他位置(甚至有可能是出库了)


**明确几个逻辑**
1. 为了确认手是否有移动, 需要把上一帧的手框保存为全局的 `old_hand`，供当前帧统一使用。`old_hand` 是本次连续手部操作的公共帧级变量，不属于任何一个物品；当前帧只计算一次 `当前手框 - old_hand` 得到本帧手部移动值，再把这一个移动值追加到当时已经处于【被手部分遮挡】或【被手完全遮挡】的每个物品自己的移动值列表中。

2. 手刚进来的时候必然只是遮挡了物品, 还没移动物品(按道理我们的算力应该允许这么快的频率), 这时后物品的变动其实很少的(大多都只是物体无意中被手碰到而导致的抖动或是yolo的抖动), 这时候这些被手遮挡了的物品的框我们也要去更新他们的box
    > 如果一个物品被手部分遮挡, 那么我们将这个物品的状态改为【被手部分遮挡】、A.shelter_or_hold=True。这一帧被手挡住后识别到的局部框，同时写入 A.first_hand_block_box 与 A.last_hand_block_box；这时不要更新 A.box。
    > 如果一个物品被手完全遮挡, 那么我们将这个物品的状态改为【被手完全遮挡】、A.shelter_or_hold=True (这时我们不要更新他的box)

3. 手没有"明确"移动的话，不做估计轨迹匹配，也不推断整理、入库或出库，避免把 YOLO 抖动当作真实移动。但对 `hold_and_move=False` 的 HAND_* 待确认物品，仍然做一次轻量的“旧位置是否仍是 A”检查；否则手停着不动时，“没有拿起”的证据就永远无法连续达到两次，候选也无法尽快释放。

4. 如果手移动了的话, 我们就只需要处理那些之前被手遮挡了的物品就行了, 其他物品不需要浪费算力去算

5. 手移动了之后，我们要先算出这个[移动值](这个移动值包含了大小与方向了), 我们查看【被手部分遮挡】与【被手完全遮挡】的物体, 看看他们变得怎么样了(要通过这个检查来确认是不是真的被手握住拿走了)
    > 物品进入上述两种状态时，`hold_and_move=False` 只表示“尚未确认”，不表示已经确认它没有移动。
    > 连续两次有效证据都支持“跟着手移动”时，才设置 `hold_and_move=True`；连续两次有效证据都支持“物品仍在旧位置”时，才恢复为【可见】。如果某一帧被手臂、其他物品或 YOLO 漏检影响，既不能支持哪一边，这是“模糊帧”：两个计数都暂停，不增加也不清零。
    > 对于【被手部分遮挡】的物体A, A.first_hand_block_box 是刚被手挡住时记录的第一个局部框，后续保持不变；A.last_hand_block_box 是上一帧实际看到的局部框，每次成功找到当前帧的 B 后都要更新。前者提供固定起点，后者用于逐帧判断物品有没有跟手移动、有没有“掉队”。
        > 如果在[当前快照]的估计位置附近找到一个与 A 有相同 cls_id 的物品B，物品B与相应参考框严格匹配，同时 A 的旧位置已经看不到 A 且没有未知物品占位，就累加一次“被手带着移动”的有效证据。
        > 如果 A 在旧位置重新被唯一匹配到，就累加一次“只是被遮挡、没有移动”的有效证据。其他情况不做二选一的强制结论。
    > 对于【被手完全遮挡】的物体A，“旧位置看不到 A”不能单独算作正向证据，因为 A 可能仍然被没有框入 YOLO 手框的手臂挡着。
        > 只有当 A 在手的估计轨迹附近重新出现并能唯一匹配时，才累加正向证据；A 在旧位置重新出现时，累加反向证据；两处都无法确认时继续保持待确认。



**注意**
这个[移动值]是要累计下来的, 只要连续有手就要一直累计。只有手没了之后才重置
`old_hand` 可以是公共变量，但移动值历史不能只放在一个公共变量里：每一个【被手部分遮挡】、【被手完全遮挡】的物品都要各自保存一个移动值列表。每处理一帧，就把本帧由 `old_hand` 和当前手框计算出的位移追加到这些物品各自的列表中；某个物品自己的总移动值，就是把它列表中的所有位移向量相加。这样即使不同物品是在不同帧才开始被手影响，它们仍然只累计从各自开始被影响之后的移动值。
因为有时候手是先晃一下然后再整理的，所以并不是一进来遮挡就只认为这几个是遮挡。手移动过程中，实时遮挡一个物品时都是要实时把这些物品改为【被手部分遮挡】或【被手完全遮挡】

**特别地**
如果一个物品A被手握住并且移动的话，这个物体A即便挡住其他物品C从而导致C看不见的话, 我们也是认为C是被手完全挡住
这样说的话, 我们要先处理那些被【被手部分遮挡】或【被手完全遮挡】
然后再来检查剩余的物品是否重新被遮挡, 这个顺序很重要
> 因此我们最好维护3+1个主要辅助结构：1个用来存储【被手部分遮挡】的id, 1个用来存储【被手完全遮挡】的id, 1个用来存储剩余的id，还有一个用来实现用 item_id 映射到 item 的字典。
> 另外有一个很小的 `released_hand_candidate_ids` 稀疏集合，只保存“已确认没有被当前这次手拿起，但手还没有真正移开”的少量 id，避免这些物品每帧又被重新建立为 HAND_* 候选。
> 这样能减少重复 for 循环和重复候选处理，而且上述 id 集合只存整数，不会复制物品对象。


**有一个问题**
我们要思考一下我们这个每帧都检查对比的方法, 到底要怎么来实现物品的入库、出库与整理, 这才是最关键的内容
一个物品要入库, 必然是手拿进来, 一个物品出库也必然是手拿出去, 一个物品被整理移动也必然是通过手来实现
也就是说只要我们把手的操作处理干净、完美就行了。在手没进到冰箱(没事别到手)的时候, 其实我们不需要浪费算力、浪费心事去像这件事
既然入库、出库、整理都跟手有关, 那么我们就需要找到能将他们三个完美区分开来的方法

1. **入库**:
> 一个物品要想入库, 必然是手拿着这个物品进来, 进来的时候有可能这个新物品是完全被手挡住的, 也有可能这个新物品是露出了一部分出来
> 所以手刚进来的时候(**识别到手的第一帧**), 应该先检查手附近是否有识别到物品B (如果有的话, 这些物品B肯定是与手贴着的, 甚至或许有一点点重叠; 而且这时手附近的物体可能不止一个, 可能有多个的), 
    > 如果没有识别到物品B的话, 有可能是手完全挡住了新物品B, 也有可能是根本没有物品B (这时只是空手进来的)
        > 这时我们就不用额外的处理, 照常的去把检查库存中也没有被手挡住的物品 (有就将他们设置成【被手部分遮挡】或【被手完全遮挡】)
    > 如果有识别到物品B的话, 有可能这些物品B是新物品, 也有可能是旧物品
        > 我们先将这些物品B的信息全都保留下来(放到列表 suspected_new_item 中), 然后再去把检查库存中也没有被手挡住的物品 (有就将他们设置成【被手部分遮挡】或【被手完全遮挡】)

**要明确一个无法解决的情况**
由于我们是单摄像头, 有可能会出现在原本一个地方有一个物体A, 然后我们又拿进了一个一模一样的物体B(同 cls_id、框的形状大小也都一样), 然后这个物品B放置的地方从摄像头角度来看的话恰好跟物体A重合, 这中情况下我们是完全无法分辨出的 (除非手拿着这个物品进来的时候我们就已经看见有个物体进来了, 否者我们是解决不了这个问题的)
这种情况如果真的出现了, 我这里直接默认他没有放入新物品, 只是单纯的手进来晃动(在我们但摄像头、无重力传感器的情况下, 这时解决不了的)



2. **整理**:
> 一个物品要想被判断为整理, 必然是手拿着这个物品移动, 然后移动到某个位置后放下了
> 因此会出现的场景是：一个库存物品A原本看得见, 然后被手遮挡, 这时有可能是物体A被手部分遮挡(部分露出来看得见), 也有可能是物体A完全被手挡住了
> 如果物体A被手部分遮挡(部分露出来看得见)
    > 如果当手移动时, 这露出的部分也会跟着一起移动, 这样我们就知道这个物品是被手握住并移动的
    > 如果手在移动的过程中, 这露出的部分并不是同步的移动的话(具体来说:可见部分的大小形状发生了明显改变), 那么这个物品就不是被手握住并移动的, 只是被手遮挡了一段时间而已
> 如果物体A被手完全遮挡
    > 如果当手移动时, 物体依旧没有重新露出来被我们看到, 这样我们就知道这个物品是被手握住并移动的
    > 如果手在移动的过程中, 物体重新露出来被我们看到, 那么这个物品就不是被手握住并移动的, 只是被手遮挡了一段时间而已

**但是要注意一个问题**
> 手进来的时候有可能会挡住靠下面的物品, 但是这些物品可能只是被手挡住但没有握起并移动
> 但是手移动的过程中这些物品被手臂遮挡了, 而由于手臂的移动幅度不大, 有可能会一直挡住这个物品, 而这个物品只是被长时间挡住而并非是被手握住并移动
1. 从这个例子我们可以知道:**一个物品长时间被手遮挡时, 不要误把他当作是被握住了, 他有可能只是单纯的被长时间挡住了而已**

> 而且还有一个情况就是: 
> 有时候yolo识别手的时候, 可能不会把手臂完整框起来(可以有一部分手臂没框上), 这时如果手臂又把部分物体遮挡了, 从而会导致这些物品又没有手挡着、又看不见
(这不能通过修改yolo的数据集来实现, 因为如果整个手臂都要框住的话, 那么手进来的时候几乎把整个屏幕的一大半都遮挡了, 只有一小部分看得见了, 这样就相当于退化到静态快照对比了, 我们辛辛苦苦的换成逐帧对比的意义就没了)
2. 从这个例子我们可以知道:**一个物品被手完全挡住后, 当手移动后即便这个物品依旧看不见, 也不能说明这个物品是被手握住并移动**
所以说, 解决这个的方法是:
> 1. 当我们允许多个物品被怀疑是[被手握住并移动]
> 2. 识别到手的期间, 只处理【被手部分遮挡】与【被手完全遮挡】的物品, 以及处理手的框的这个部分。其他地方最好不要理(不理就不会错)
> 3. 但是我们拿到十分自信的证据的时候, 不要轻易的判断一个物品是[整理]到其他位置, 或[出库]
    > 对于【被手部分遮挡】的物体并且hold_and_move, 其实处理相对简单一点：因为他的框我们一直都可以看得见, 所以我们可以一直跟踪他的框的位置, 然后等都某一刻手一直在移动, 但是这个框移动的不如手移动的远(甚至没移动了), 也就是说这个物品"掉队了"，这时候用新的框与原来的框比较，看他的大小关系是不是包含关系，是的话就很大概率说明是这个物品放下了
    > 对于【被手部分遮挡】的物体并且hold_and_move, 其实处理也不难：这时由于他看不到物品是怎么动的，但是他看得到手是怎么动的, 所以我们可以一直跟踪手的框的位置, 然后等都某一刻手一直在移动, 但是这个手附近(与手的框贴着)突然多了一个物品，然后检查这个多了的物品是否能跟其他物品匹配，如果能的话就很大概率说明这个物品北方下了


3.**出库**
> 一个物品要想被判断为出库, 必然是手拿着这个物品移动, 然后直到手离开了也一直都没有放下, 并且最后手离开了也看不到这个物品重新出现

# .first_hand_block_box 与 .last_hand_block_box 属性
当一个库存物品刚变成【被手部分遮挡】时，把这一帧被手挡住后仍能看见的局部框同时写入 `first_hand_block_box` 和 `last_hand_block_box`。这个框通常比没有被手遮挡时的完整框小；物品没有被手遮挡时的旧位置仍然保存在 `box` 中。
`first_hand_block_box` 只在刚进入【被手部分遮挡】状态时赋值一次，后续保持不变；它是本段手遮挡的第一个局部参考框。
`last_hand_block_box` 表示上一帧（更准确地说，最近一次）实际匹配到的手遮挡局部框。当前帧成功匹配到同一物品后，就把它更新为当前检测框，供下一帧使用。
这两个属性都只在【被手部分遮挡】期间有值。物品恢复【可见】、完成整理或本段手操作结束时，两者都清空；【被手完全遮挡】时两者为 `None`。


# .move_values 属性
`move_values` 是每个物品自己的位移列表。只有【被手部分遮挡】或【被手完全遮挡】的物体在本次手部操作期间持续追加位移；其他物品不追加。
列表中的每个元素都是一帧的手部位移向量，方向和大小都保留。需要估计物品当前位置时，把列表中的向量逐个相加，得到“净位移向量”；如果需要知道手实际走过的总路程，则把每个向量的长度相加，这两个量不能混为一谈。不能用其他物品的列表替代。
手离开冰箱后(当前快照检测不到手)清空所有物品的 `move_values`；某个物品结束【被手部分遮挡】或【被手完全遮挡】状态时，也清空它自己的列表。


# .track 属性
记录物体(疑似)被手握住并移动时, 物体的在这个轨迹上的所有估计框
.track 是一个"队列", 每帧都将他的估计框的位置入到队尾
当一个物品被手握住并移动, 但是没有发现被方向来的时候, 看这个路径上有这个物品, 如果整条路径上都无法匹配上的话, 就说明出库了
一开始的位置也要输入 .track 中


# .block_ids 属性
> block_ids 只记录按照当前业务流程判断为位于目标物品前方, 并且与目标物品 base_box 存在有效交集的物品
> 因此, 后续使用 block_ids 中的物品进行 apply_cover 时, 可以直接把它们当作前方遮挡物
> **整理后重新放置的物品, 以及本轮确认入库的新物品, 都视为位于发生重叠的旧物品前方**
(.block_ids 不是一个数, 而是一个集合set, 他要允许记录多个物品信息记录, 而且能自动**去重**)


# suspected_new_item 列表
> 用来存储怀疑是新物品的列表
> 每次手进来的第一帧, 手附近与手贴着的物品B, 这些物品B会进入到这个列表
> 手移动后, 手原先的地方出现没见过的物品, 这些物品B会进入到这个列表
> 注意：suspected_new_item 要区分开[第一批]与[非第一批]
    > 这些第一帧就进来的这些物品B与之后进来的那些物品的操作有所不同
    > [第一批]的物品, 只需要他第二帧第三帧发现匹配不上这些物品后, 这些匹配不上的物品就出库了


# apply_cover 函数
> 这个函数用来检测 A 是否被完全遮挡
> apply_cover 的作用、完整定义和判定条件见《矩形动态遮挡问题说明.md》


# hand_track
`hand_track` 是本段连续手操作中所有物品共用的一份手框列表，每帧只把当前手框追加一次，不能为每个物品重复复制整条手轨迹。
每个被手影响的物品只记录自己的 `hand_track_start_index`。某个物品开始进入【被手部分遮挡】或【被手完全遮挡】时，把当前手框在公共列表中的下标记录下来；需要该物品对应的手轨迹时，直接读取 `hand_track[hand_track_start_index:]`。
因此，不同物品即使从不同帧开始被手遮挡，也会自然得到各自正确的轨迹片段。物品结束本段手影响时清空自己的起始下标；手离开冰箱并完成收尾后，清空公共 `hand_track`。

class InventoryItem:

    cls_id: int

    # box 是当前/上一次确认看见的位置；base_box 是可靠的完整位置。
    # 一旦进入 HAND_*，本轮手操作中不再更新 box；此时 box 就是 A 移动前的旧位置。
    box: BBox
    base_box: BBox
    status: str                         # 四种状态之一
    block_ids: set[int]                 # 在本业务中已确认位于它前方的物品

    # 以下都是一次连续有手操作期间的临时字段 (没被手遮挡时, 下面这些完全用不上, 也不用管)。
    shelter_or_hold: bool = False
    # HAND_* 且 False 表示“仍待确认”，不表示已经确认没有移动。
    hold_and_move: bool = False
    hold_evidence_count: int = 0       # 连续支持“被手握住并移动”的有效证据数
    not_hold_evidence_count: int = 0   # 连续支持“只被遮挡、没有移动”的有效证据数
    first_hand_block_box: BBox | None = None  # 刚被手部分遮挡时的第一个局部框；只赋值一次
    last_hand_block_box: BBox | None = None   # 最近一次实际看到的手遮挡局部框；逐帧更新
    # 构造每个 InventoryItem 时都新建一个空列表，不能让不同实例共享同一个列表。
    move_values: list[Vector] = []      # 每个实例独立的逐帧手移动值列表
    track: deque[BBox] = deque()        # 该物品被怀疑随手移动时的完整估计框
    hand_track_start_index: int | None = None  # 该物品开始受手影响时，在公共 hand_track 中的下标
    release_box: BBox | None = None


class SuspectedNewItem:
    # 它只是“疑似手带进来的物品”，尚未写入 inventory。
    cls_id: int
    first_box: BBox
    last_box: BBox
    first_batch: bool                   # 手刚进来的第一帧收集到的，才是 True
    missing_after_entry_frames: int = 0


class Snapshot:
    hand: BBox | None
    foods: list[Detection]              # Detection: cls_id, box, score


# 跨关门持久保存的“已提交库存”。正式库存只在提交工作库存时修改。
inventory_by_id: dict[int, InventoryItem] = {}   # item_id ——> item 的映射字典
next_item_id: int = 1       # 用于给新进来的物品 item_id
local_inventory_loaded: bool = False    # 是否有本地库存

# 只在本次连续手操作中存在的“工作库存”；实际字典就是 item_by_id。
working_inventory_active: bool = False

# 只在本次开门/本段连续有手操作中存在。
previous_snapshot: Snapshot | None = None
old_hand: BBox | None = None
hand_track: list[BBox] = []             # 本段连续手操作共用的一份手框轨迹
suspected_new_items: list[SuspectedNewItem] = []    # 记录可能是新物品的物品

# 这 3 个列表只存 item_id；item_by_id 直接映射到库存对象。
hand_partial_blocked_ids: set[int] = set()   # 记录状态为【被手部分遮挡】的物品的 item_id
hand_full_blocked_ids: set[int] = set()      # 记录状态为【被手完全遮挡】的物品的 item_id
remaining_item_ids: set[int] = set()         # 记录状态不是【被手部分遮挡】也不是【被手完全遮挡】的物品的 item_id
# 已经连续确认“只是被当前这次手遮挡”的 item。
# 手真正移开该 item 前不重复建立 HAND_* 候选；移开后即从集合中删除。
released_hand_candidate_ids: set[int] = set()
# 所有逐帧业务函数都通过 item_by_id 访问工作库存；不要直接改 inventory_by_id。
item_by_id: dict[int, InventoryItem] = {}
# 明确确认过的出库候选；工作库存中消失但未进入这里的物品，不得直接判 OUT。
pending_out_by_id: dict[int, InventoryItem] = {}

# 交集面积
def intersection_area(box_a, box_b) -> float:
    left = max(box_a.x1, box_b.x1)
    top = max(box_a.y1, box_b.y1)
    right = min(box_a.x2, box_b.x2)
    bottom = min(box_a.y2, box_b.y2)
    if right <= left or bottom <= top:
        return 0.0
    return (right - left) * (bottom - top)

# 面积
def box_area(box) -> float:
    return max(0.0, box.w) * max(0.0, box.h)

# IoM
def IoM(box_a, box_b) -> float:
    denominator = min(box_area(box_a), box_area(box_b))
    if denominator <= 0:
        return 0.0
    return intersection_area(box_a, box_b) / denominator

# 中心坐标
def center(box) -> Vector:
    return Vector(dx=box.cx, dy=box.cy)

# 中心距离
def center_distance(box_a, box_b) -> float:
    return sqrt((box_a.cx - box_b.cx) ** 2 + (box_a.cy - box_b.cy) ** 2)

# 对角线长度
def length(vector) -> float:
    return sqrt(vector.dx ** 2 + vector.dy ** 2)

# 两个矩形边缘之间的最短距离。
# 相交或刚好相贴时为 0；只看中心距离不能表达“两个框的边缘相贴”。
def box_edge_distance(box_a, box_b) -> float:
    horizontal_gap = max(box_a.x1 - box_b.x2, box_b.x1 - box_a.x2, 0.0)
    vertical_gap = max(box_a.y1 - box_b.y2, box_b.y1 - box_a.y2, 0.0)
    return sqrt(horizontal_gap ** 2 + vertical_gap ** 2)

# 覆盖率
def cover_ratio(target, cover) -> float:
    target_area = box_area(target)
    if target_area <= 0:
        return 0.0
    return intersection_area(target, cover) / target_area

# 通过中心距离来判断两个框是否足够接近
def box_near(box_a, box_b) -> bool:
    return center_distance(box_a, box_b) <= BOX_NEAR_DISTANCE

def open_fridge():
    global inventory_by_id, next_item_id, local_inventory_loaded
    # 开门前清空相关内容
    clear_session_runtime_state()

    if has_local_inventory():
        # 有本地库存时，直接把它作为本次开门的 inventory。
        return

    # 如果没有本地库存, 就向后台申请
    backend_inventory = request_inventory_from_backend()
    # 获取一张没有手的快照
    first_snapshot = wait_for_first_no_hand_snapshot()

    if backend_inventory is not None:
        # 按前文的“单向检查”：只校验首张无手快照，检查不通过不修改库存。
        if not initial_one_way_check(backend_inventory, first_snapshot.foods):

        load_inventory(backend_inventory)

    inventory_by_id, next_item_id = make_inventory_from_snapshot(first_snapshot.foods)
    local_inventory_loaded = True   # 是否有本地库存

## 1. 基础匹配、框和遮挡函数

```python
# 严格匹配
def strict_box_match(A_cls, A_box, B_cls, B_box) -> bool:
    """前文的严格匹配：类别相同，中心、宽、高都足够接近。"""
    return (
        A_cls == B_cls
        and center_distance(A_box, B_box) <= STRICT_CENTER_DISTANCE
        and abs(A_box.w - B_box.w) <= STRICT_WIDTH_DELTA
        and abs(A_box.h - B_box.h) <= STRICT_HEIGHT_DELTA
    )

# 严格匹配(便捷包装)
def strict_match(A, B) -> bool:
    return strict_box_match(A.cls_id, A.box, B.cls_id, B.box)

# 局部匹配(便捷包装)
def partial_match(A, B) -> bool:
    """前文的局部匹配：类别相同，IoM 接近 1。"""
    return A.cls_id == B.cls_id and IoM(A.box, B.box) >= PARTIAL_IOM

# 物体A是否与手框相贴
# 相贴不是“中心接近”：A 的边缘要靠近手框，同时 A 与手的交集必须很小。
# 因此它适合找“手边可能拿着的新物品”，不能拿来判定手已遮住库存物品。
def hand_is_near(hand_box, A_box) -> bool:
    return (
        box_edge_distance(hand_box, A_box) <= HAND_ATTACH_DISTANCE
        and intersection_area(hand_box, A_box) <= HAND_NEAR_MAX_INTERSECTION_AREA
    )


# 物体A与手的交集是否足够大
def hand_has_meaningful_overlap(hand_box, A_box) -> bool:
    return intersection_area(hand_box, A_box) >= HAND_PARTIAL_OVERLAP_AREA

# 手对物体A的覆盖率是否足够高 (覆盖率为1时就是手完全覆盖物体A) 
def hand_fully_covers(hand_box, object_box) -> bool:
    return cover_ratio(target=object_box, cover=hand_box) >= HAND_FULL_COVER_RATIO

# 手是否明确移动
def hand_has_explicit_move(hand_box, old_hand_box) -> bool:
    # 小抖动不算“明确移动”。
    return center_distance(hand_box, old_hand_box) >= HAND_MOVE_DISTANCE

# 一个框根据某个物品的总移动值后的估计框的位置
def move_box(box, total_move_value) -> BBox:
    return BBox(
        x1=box.x1 + total_move_value.dx,
        y1=box.y1 + total_move_value.dy,
        x2=box.x2 + total_move_value.dx,
        y2=box.y2 + total_move_value.dy,
    )

# 唯一严格匹配：适合完整、位置基本不变的物品。
def unique_detection_strict_matching_item(item, detections) -> Detection | None:
    candidates = [D for D in detections if strict_match(item, D)]
    return candidates[0] if len(candidates) == 1 else None

# 唯一局部匹配：适合物品露出部分、框与原框有包含关系的情况。
# 调用方自行决定是否允许它作为严格匹配失败后的后备方案。
def unique_detection_partial_matching_item(item, detections) -> Detection | None:
    candidates = [D for D in detections if partial_match(item, D)]
    return candidates[0] if len(candidates) == 1 else None

# 更新正式库存
def commit_working_inventory():
    """
    本段连续手操作结束且通过最终检查后，将工作副本的最终结果一次性提交为正式库存。
    手还在时只使用/修改 item_by_id 工作副本，不修改 inventory_by_id。
    """
    global inventory_by_id, item_by_id
    global working_inventory_active

    if not working_inventory_active:
        return

    # 正式库存不能带 HAND_* 和轨迹等本轮临时字段。
    for item in item_by_id.values():
        if item.status in {HAND_PARTIAL_BLOCKED, HAND_FULL_BLOCKED}:
            item.status = VISIBLE
        item.shelter_or_hold = False
        item.hold_and_move = False
        item.hold_evidence_count = 0
        item.not_hold_evidence_count = 0
        item.first_hand_block_box = None
        item.last_hand_block_box = None
        item.move_values.clear()
        item.track.clear()
        item.hand_track_start_index = None
        item.release_box = None

    # 一次遍历旧库存：同时生成正式事件，并构建仍要保留的正式库存。
    new_inventory = {}
    for item_id, old_item in inventory_by_id.items():
        new_item = item_by_id.get(item_id)
        if new_item is None:
            if item_id in pending_out_by_id:
                emit_event("OUT", old_item, before_box=old_item.box)
            else:
                # 没有明确出库记录的缺失 item 视为未决，保留正式库存，不发 OUT。
                new_inventory[item_id] = deep_copy(old_item)
            continue

        new_inventory[item_id] = deep_copy(new_item)

        if not strict_box_match(
            old_item.cls_id, old_item.base_box,
            new_item.cls_id, new_item.base_box,
        ):
            emit_event(
                "MOVED",
                new_item,
                before_box=old_item.base_box,
                after_box=new_item.base_box,
            )

        if old_item.status != new_item.status:
            if new_item.status == OCCLUDED:
                emit_event("OCCLUDED", new_item)
            elif old_item.status == OCCLUDED and new_item.status == VISIBLE:
                emit_event("REVEALED", new_item)

    for item_id, new_item in item_by_id.items():
        if item_id not in inventory_by_id:
            new_inventory[item_id] = deep_copy(new_item)
            emit_event("IN", new_item)

    inventory_by_id = new_inventory

    item_by_id = {}
    pending_out_by_id.clear()
    working_inventory_active = False

# 用来找前一个快照中的物体A是否在当前快照中移动了(由于A不是库存中的, 所以不能用itemt_id, 只能这样输入A_box与cls_id)
def unique_detection_near_box(A_box, cls_id, detections) -> Detection | None:
    """寻找类别相同、位置在 A_box 附近且框大小形状严格匹配的唯一 Detection。"""
    candidates = []
    for D in detections:
        if D.cls_id != cls_id:
            continue
        if box_near(D.box, A_box) and box_shape_strict_match(D.box, A_box):
            candidates.append(D)
    return candidates[0] if len(candidates) == 1 else None

# 物品 D 是否能与 [已确认被手握住并移动的物品] 的最新的一个估算框"勉强匹配"
def detection_matches_any_held_item(D) -> bool:
    """
    物品 D 是否能与 [已确认被手握住并移动的物品] 的最新的一个估算框"勉强匹配"
    "勉强匹配"的意思是在这个估算框的附近, 标签D与这个物品的原始框的形状大小也相近
    如果匹配上了的话, 就很大概率说明这个物品D就是放下了的, 能用来判断[整理]
    """
    for item_id in hand_partial_blocked_ids | hand_full_blocked_ids:
        # 遍历【被手部分遮挡】与【被手完全遮挡】的库存物品
        item = item_by_id.get(item_id)
        if item is None or not item.hold_and_move or not item.track:
            continue
        if box_near(D.box, item.track[-1]) and box_shape_strict_match(D.box, item.track[-1]):
            return True
    return False


def old_position_is_clean(old_A_box, A_cls_id, A_item_id, current_foods) -> bool:
    """
    只检查 A 的旧位置，不判断 A 在当前帧的其他位置出现了没有。

    old_A_box：A 进入 HAND_* 前的上一帧 A.box，本轮手操作中保持不变。
    A_cls_id、A_item_id：旧库存物品 A 的类别和 ID。
    current_foods：当前快照的 YOLO Detection 列表；其中每个 D 都还没有 item_id。

    返回 True 表示：旧位置没有看到 A，也没有未知物品占据旧位置。
    这只是“A 已移动”的必要证据之一，不单独确认 A 已移动。
    """
    for D in current_foods:
        # 与 A 的旧位置无关的当前检测框不参与本函数判断。
        if intersection_area(old_A_box, D.box) <= OLD_POSITION_OVERLAP:
            continue

        # D 位于旧位置，且与旧 A 的框局部匹配：说明 A 仍在原处，并没有移走。
        D_is_A_at_old_position = (
            D.cls_id == A_cls_id
            and IoM(old_A_box, D.box) >= PARTIAL_IOM
        )
        if D_is_A_at_old_position:
            return False

        # D 位于旧位置但不是 A 时，先确认它是不是另一件已知库存物品。
        D_is_known_other_inventory_item = any(
            other.item_id != A_item_id and partial_match(other, D)
            for other in item_by_id.values()
        )
        if not D_is_known_other_inventory_item:
            # 只有“占据旧位置 + 不属于任何旧库存”的 D，才是未知物品。
            return False
    return True


def find_A_at_old_position(item, current_foods) -> Detection | None:
    """
    在 A 进入 HAND_* 前的旧 item.box 上，寻找唯一能与 A 局部匹配的检测框。

    返回 Detection 表示“A 仍在旧位置”；返回 None 只表示无法唯一确认，
    不能反向推导 A 已经移走。同类同位置的新物品与旧 A 在单摄像头下无法区分，
    这里按前文约定当作 A 仍在原位。
    """
    candidates = []
    for D in current_foods:
        if intersection_area(item.box, D.box) <= OLD_POSITION_OVERLAP:
            continue
        if D.cls_id == item.cls_id and IoM(item.box, D.box) >= PARTIAL_IOM:
            candidates.append(D)
    return candidates[0] if len(candidates) == 1 else None


def is_fully_covered(item) -> bool:
    return is_fully_covered_by_block_ids(
        item=item,
        item_by_id=item_by_id,
        remaining_area_eps=COVER_REMAINING_AREA_EPS,
    )
```

def remove_item_from_all_block_ids(item_id):
    for item in item_by_id.values():
        item.block_ids.discard(item_id)


def update_block_ids_as_front(front_item):
    """
    前文规定：确认整理后重新放下的物品、确认入库的新物品，
    如果与旧物品 base_box 相交，都视为位于旧物品前方。
    """

    for target in item_by_id.values():
        if target.item_id == front_item.item_id:
            continue
        if intersection_area(target.base_box, front_item.base_box) > BLOCK_OVERLAP_AREA_EPS:
            target.block_ids.add(front_item.item_id)


def refresh_normal_occlusion(current_foods):
    """
    这里只处理普通【遮挡】和【可见】，不处理被手遮挡的物品。
    由确认放下/确认入库，或手离开后调用。
    """
    for item in item_by_id.values():
        if item.status in {HAND_PARTIAL_BLOCKED, HAND_FULL_BLOCKED}:
            continue

        # 普通可见状态优先严格匹配；框被普通遮挡而只露出部分时才退到局部匹配。
        D = unique_detection_strict_matching_item(item, current_foods)
        if D is None:
            D = unique_detection_partial_matching_item(item, current_foods)

        if D is not None:
            # 看得到时，先更新当前 box；base_box 只在确认整理时换位置。
            item.box = D.box
            if item.status == OCCLUDED and not is_fully_covered(item):
                item.status = VISIBLE
                emit_working_event("REVEALED", item)
            continue

        # 当前没检测到 item，只有被 block_ids 的前方物品完整盖住时，
        # 才把它变为普通【遮挡】。
        if item.status == VISIBLE and is_fully_covered(item):
            item.status = OCCLUDED
            emit_working_event("OCCLUDED", item)

## 3. 手刚进入时：先记录疑似入库物品，再标记被手遮挡物品

```python
def append_suspected_new_item(D, first_batch):
    # 同一 Detection 不要在同一批次重复进入 suspected_new_item。
    if any(
        strict_box_match(S.cls_id, S.last_box, D.cls_id, D.box)
        for S in suspected_new_items
    ):
        return

    suspected_new_items.append(
        SuspectedNewItem(
            cls_id=D.cls_id,
            first_box=D.box,
            last_box=D.box,
            first_batch=first_batch,
        )
    )


def collect_first_batch_suspected_new_items(hand, current_foods):
    """识别到手的第一帧：手附近的每个物品都先保留为第一批疑似入库物品。"""
    for D in current_foods:
        # 第一批候选要求与手框相贴；允许极小交集以容忍检测框抖动。
        if hand_is_near(hand, D.box):
            append_suspected_new_item(D, first_batch=True)


def begin_hand_operation(hand, current_foods):
    # 从已提交库存创建本次连续手操作的工作副本。
    begin_working_inventory()
    hand_track.clear()
    hand_track.append(hand)
    released_hand_candidate_ids.clear()
    collect_first_batch_suspected_new_items(hand, current_foods)

    # 必须在记录第一批疑似新物品之后，再检查库存中哪些旧物品被手遮挡。
    mark_newly_hand_blocked_items(hand, current_foods)


def iter_item_hand_track(item):
    """按需读取 item 对应的公共手轨迹，不复制一份 BBox 列表。"""
    if item.hand_track_start_index is None:
        return
    for index in range(item.hand_track_start_index, len(hand_track)):
        yield hand_track[index]


def enter_hand_partial_blocked(item, visible_detection):
    item.status = HAND_PARTIAL_BLOCKED
    item.shelter_or_hold = True
    item.hold_and_move = False
    item.hold_evidence_count = 0
    item.not_hold_evidence_count = 0

    # 这两个框都是“被手挡住后”的局部框，不是未遮挡时的完整 item.box。
    # first 只记录本段手遮挡的第一帧；last 会在后续成功匹配时逐帧更新。
    item.first_hand_block_box = visible_detection.box
    item.last_hand_block_box = visible_detection.box
    if item.hand_track_start_index is None:
        item.hand_track_start_index = len(hand_track) - 1
    item.move_values.clear()
    item.track = deque([item.base_box])

    hand_partial_blocked_ids.add(item.item_id)
    hand_full_blocked_ids.discard(item.item_id)
    remaining_item_ids.discard(item.item_id)


def enter_hand_full_blocked(item):
    item.status = HAND_FULL_BLOCKED
    item.shelter_or_hold = True
    item.hold_and_move = False
    item.hold_evidence_count = 0
    item.not_hold_evidence_count = 0
    item.first_hand_block_box = None
    item.last_hand_block_box = None
    if item.hand_track_start_index is None:
        item.hand_track_start_index = len(hand_track) - 1
    item.move_values.clear()
    item.track = deque([item.base_box])

    hand_full_blocked_ids.add(item.item_id)
    hand_partial_blocked_ids.discard(item.item_id)
    remaining_item_ids.discard(item.item_id)


def mark_newly_hand_blocked_items(hand, current_foods):
    """
    只检查尚未被处理的旧库存物品。
    原本处于普通【遮挡】的物品不在这里当作新的手遮挡候选。
    """
    # 某个 item 已经连续确认“只是被遮挡”后，只要手还没有
    # 真正离开它，就不要在每帧末尾又把它重新加入 HAND_* 候选。
    # 手一旦移开，立即解除这个抑制；以后手再回来真正拿它时仍能重新处理。
    for item_id in list(released_hand_candidate_ids):
        item = item_by_id.get(item_id)
        if item is None:
            released_hand_candidate_ids.discard(item_id)
            continue

        D = unique_detection_strict_matching_item(item, current_foods)
        if D is None:
            D = unique_detection_partial_matching_item(item, current_foods)

        hand_still_affects_item = (
            D is not None and hand_has_meaningful_overlap(hand, D.box)
        ) or (
            D is None and hand_fully_covers(hand, item.base_box)
        )
        if not hand_still_affects_item:
            released_hand_candidate_ids.discard(item_id)

    remaining_item_ids.clear()
    remaining_item_ids.update(item_by_id.keys())
    remaining_item_ids -= hand_partial_blocked_ids
    remaining_item_ids -= hand_full_blocked_ids
    remaining_item_ids -= released_hand_candidate_ids

    for item_id in list(remaining_item_ids):
        item = item_by_id[item_id]
        if item.status == OCCLUDED:
            continue

        # 先用完整框的严格对应；部分露出时才允许局部对应。
        D = unique_detection_strict_matching_item(item, current_foods)
        if D is None:
            D = unique_detection_partial_matching_item(item, current_foods)
        # 进入“被手部分遮挡”必须有足够大的实际交集，不能只因为相贴。
        if D is not None and hand_has_meaningful_overlap(hand, D.box):
            enter_hand_partial_blocked(item, D)
        elif D is None and hand_fully_covers(hand, item.base_box):
            enter_hand_full_blocked(item)
```

## 4. 手移动时：先处理已有被手遮挡物品，再处理新遮挡物品

```python
def append_frame_move_value(item, frame_hand_delta):
    """把本帧公共的手部位移，追加到某个物品自己的历史列表。"""
    item.move_values.append(copy(frame_hand_delta))


def append_frame_move_value_to_hand_affected_items(frame_hand_delta):
    """
    当前帧只根据全局 old_hand 和当前手框计算一次 frame_hand_delta，
    然后追加给本帧开始处理前已经处于 HAND_* 状态的物品。
    本帧刚刚被手遮挡的物品从下一帧开始累计，避免把它被发现之前的移动算进去。
    """
    affected_ids = hand_partial_blocked_ids | hand_full_blocked_ids
    for item_id in affected_ids:
        item = item_by_id.get(item_id)
        if item is not None:
            append_frame_move_value(item, frame_hand_delta)


def total_item_move_value(item) -> Vector:
    """把一个物品自己的位移列表相加，得到用于估计位置的净位移向量。"""
    total = Vector(0, 0)
    for delta in item.move_values:
        total = total + delta
    return total


def total_item_move_distance(item) -> float:
    """如果需要实际走过的总路程，就累加每一帧位移向量的长度。"""
    return sum(length(delta) for delta in item.move_values)


def append_estimated_track_box(item):
    # track 的每个点始终是完整物品的估计框，不直接把局部 Detection 当完整框。
    item.track.append(move_box(item.base_box, total_item_move_value(item)))


def reset_hand_state_to_visible(item):
    """
    清理 item 的本段 HAND_* 临时状态，并让它回到【可见】。

    本函数不修改 item.box/base_box：连续确认“没有移动”时，
    调用方先用旧位置的当前 Detection 更新 item.box；手离开但仍无法确认时，
    调用方不改坐标，就会保留进入本段 HAND_* 前的最后工作库位置。
    """
    item.status = VISIBLE
    item.shelter_or_hold = False
    item.hold_and_move = False
    item.hold_evidence_count = 0
    item.not_hold_evidence_count = 0
    item.first_hand_block_box = None
    item.last_hand_block_box = None
    item.move_values.clear()
    item.track.clear()
    item.hand_track_start_index = None
    item.release_box = None
    hand_partial_blocked_ids.discard(item.item_id)
    hand_full_blocked_ids.discard(item.item_id)


def update_pending_items_without_hand_move(current_foods):
    """
    手本帧没有明确移动时，不做估计轨迹匹配和整理/出库推断；
    但对仍为 hold_and_move=False 的 HAND_* 候选，可以做一次很轻量的
    “A 是否仍在旧位置”检查。

    这样手只是挡在 A 前面而没有拿动它时，也能在两个有效帧后尽快释放 A；
    否则“手不动就全部跳过”会让反向证据永远无法达到两次。
    """
    affected_ids = hand_partial_blocked_ids | hand_full_blocked_ids
    for item_id in list(affected_ids):
        item = item_by_id.get(item_id)
        if item is None or item.hold_and_move:
            continue

        A_at_old_position = find_A_at_old_position(item, current_foods)
        if A_at_old_position is None:
            # 旧位置看不清时仍是模糊帧，计数保持不变。
            continue

        item.not_hold_evidence_count += 1
        item.hold_evidence_count = 0
        if item.not_hold_evidence_count >= NOT_HOLD_EVIDENCE_REQUIRED:
            item.box = A_at_old_position.box
            reset_hand_state_to_visible(item)
            released_hand_candidate_ids.add(item.item_id)


def update_partially_hand_blocked_item(item, hand, frame_hand_delta, current_foods):
    """
    first_hand_block_box 是固定起点；last_hand_block_box 是上一帧实际局部框。
    用 last_hand_block_box + 本帧手移动值估计当前局部框；
    逐帧衔接失败时，再用 first_hand_block_box + 总移动值尝试重新找回；
    当前帧成功匹配后只更新 last_hand_block_box。
    在当前快照中寻找同类、形状大小严格匹配的 B。
    """
    hand_move = length(frame_hand_delta)
    # 首选“上一帧局部框 + 本帧移动值”，用于正常的逐帧跟踪。
    expected_from_last_box = move_box(
        item.last_hand_block_box,
        frame_hand_delta,
    )
    B = unique_detection_near_box(
        expected_from_last_box, item.cls_id, current_foods
    )

    if B is None:
        # 如果中间发生过漏检，上一帧局部框可能无法继续逐帧衔接；
        # 再用“第一个局部框 + 本物品总移动值”尝试重新找回。
        expected_from_first_box = move_box(
            item.first_hand_block_box,
            total_item_move_value(item),
        )
        B = unique_detection_near_box(
            expected_from_first_box, item.cls_id, current_foods
        )

    # 即使还没有确认 hold_and_move，也要保留候选路径。
    # 如果后面连续确认它没有移动，reset 会丢弃这条候选 track。
    append_estimated_track_box(item)

    # hold_and_move 一旦已经由两次有效证据确认，就不再重复做
    # “到底有没有被拿起”的高成本检查，只继续跟踪和判断放下。
    if item.hold_and_move:
        if B is None:
            return
        previous_hand_block_box = item.last_hand_block_box
        item.last_hand_block_box = B.box
        try_confirm_partial_item_placed(
            item, previous_hand_block_box, B, hand_move, current_foods
        )
        return

    # False 在 HAND_* 中是 PENDING，要先寻找反向证据：A 是否仍在旧位置。
    A_at_old_position = find_A_at_old_position(item, current_foods)
    if A_at_old_position is not None:
        item.not_hold_evidence_count += 1
        item.hold_evidence_count = 0

        if item.not_hold_evidence_count >= NOT_HOLD_EVIDENCE_REQUIRED:
            item.box = A_at_old_position.box
            reset_hand_state_to_visible(item)
            released_hand_candidate_ids.add(item.item_id)
        return

    # 正向证据必须同时满足：在估计位置找到 B，而且旧位置干净。
    # old_position_is_clean=False 还可能是“未知物品占位”，因此不能当成反向证据。
    old_position_clean = old_position_is_clean(
        old_A_box=item.box,
        A_cls_id=item.cls_id,
        A_item_id=item.item_id,
        current_foods=current_foods,
    )
    if B is not None and old_position_clean:
        previous_hand_block_box = item.last_hand_block_box
        item.last_hand_block_box = B.box
        item.hold_evidence_count += 1
        item.not_hold_evidence_count = 0

        if item.hold_evidence_count >= HOLD_EVIDENCE_REQUIRED:
            item.hold_and_move = True
            item.hold_evidence_count = 0
            item.not_hold_evidence_count = 0
            try_confirm_partial_item_placed(
                item, previous_hand_block_box, B, hand_move, current_foods
            )
        return

    # B 找不到，或者旧位置被未知物品占用，都是模糊帧。
    # 模糊帧不增加、也不清零任何证据计数，避免 hold_and_move 永远卡在 False。
    if B is not None:
        # 虽然本帧不能证明是否被握住，但它仍可以作为下帧的局部跟踪参考。
        item.last_hand_block_box = B.box


def update_fully_hand_blocked_item(item, hand, current_foods):
    """
    完全遮挡时，“旧位置看不到 A”不能证明 A 被拿走，
    因为没有被 YOLO 框住的手臂也可能一直遮挡 A。
    """
    append_estimated_track_box(item)

    if item.hold_and_move:
        try_confirm_full_item_placed(item, hand, current_foods)
        return

    A_at_old_position = find_A_at_old_position(item, current_foods)
    if A_at_old_position is not None:
        item.not_hold_evidence_count += 1
        item.hold_evidence_count = 0

        if item.not_hold_evidence_count >= NOT_HOLD_EVIDENCE_REQUIRED:
            item.box = A_at_old_position.box
            reset_hand_state_to_visible(item)
            released_hand_candidate_ids.add(item.item_id)
        return

    # 完全遮挡的 A 只有在当前估计轨迹附近重新出现时，
    # 才有“它确实跟着手移动”的正向证据。
    expected_box = item.track[-1]
    B = unique_detection_near_box(expected_box, item.cls_id, current_foods)
    if B is not None:
        B_matches_other_item = any(
            other.item_id != item.item_id and strict_match(other, B)
            for other in item_by_id.values()
        )
        if B_matches_other_item:
            B = None

    old_position_clean = old_position_is_clean(
        old_A_box=item.box,
        A_cls_id=item.cls_id,
        A_item_id=item.item_id,
        current_foods=current_foods,
    )
    if B is None or not old_position_clean:
        # 这是模糊帧，不变更两个证据计数。
        return

    item.hold_evidence_count += 1
    item.not_hold_evidence_count = 0
    if item.hold_evidence_count >= HOLD_EVIDENCE_REQUIRED:
        item.hold_and_move = True
        item.hold_evidence_count = 0
        item.not_hold_evidence_count = 0
        try_confirm_full_item_placed(item, hand, current_foods)


def collect_non_first_batch_suspected_new_items(old_hand, current_foods):
    """
    手移动后，手原先的位置出现一个库存中没有见过的物品时，加入非第一批。
    """
    for D in current_foods:
        # 这里是“旧手框所在的操作区域”筛候选：物品可能与旧手框相贴，
        # 也可能原先被手压住、手移开后才完整露出，所以两种情况都保留。
        if not (
            hand_is_near(old_hand, D.box)
            or hand_has_meaningful_overlap(old_hand, D.box)
        ):
            continue
        # 入库候选排除：只用局部匹配识别可能已经存在的旧库存物品。
        if any(partial_match(item, D) for item in item_by_id.values()):
            continue
        if detection_matches_any_held_item(D):
            continue
        append_suspected_new_item(D, first_batch=False)


def process_moved_hand_frame(hand, frame_hand_delta, current_foods):
    """
    顺序不能交换：
    1. 先处理上一时刻已被手部分/完全遮挡的 item；
    2. 再处理手移动后新出现的疑似入库物品；
    3. 最后才检查剩余 item 是否在这一帧新被手遮挡。
    """
    for item_id in list(hand_partial_blocked_ids):
        item = item_by_id.get(item_id)
        if item is not None:
            update_partially_hand_blocked_item(
                item, hand, frame_hand_delta, current_foods
            )

    for item_id in list(hand_full_blocked_ids):
        item = item_by_id.get(item_id)
        if item is not None:
            update_fully_hand_blocked_item(item, hand, current_foods)

    collect_non_first_batch_suspected_new_items(old_hand, current_foods)
    mark_newly_hand_blocked_items(hand, current_foods)
```

## 5. 确认“放下”并完成整理

```python
def hand_keeps_moving_but_item_falls_behind(previous_hand_block_box, current_box, hand_move) -> bool:
    """
    前文中“手一直在移动，但物品框移动得不如手远、甚至不动”的条件。
    同时要求前后局部框仍满足包含/局部关系，排除完全不同的 Detection。
    """
    if previous_hand_block_box is None:
        return False

    item_move = center_distance(current_box, previous_hand_block_box)
    return (
        hand_move >= HAND_MOVE_DISTANCE
        and item_move <= hand_move * ITEM_FALL_BEHIND_RATIO
        and IoM(previous_hand_block_box, current_box) >= PARTIAL_IOM
    )


def try_confirm_partial_item_placed(item, previous_hand_block_box, B, hand_move, current_foods):
    if not item.hold_and_move:
        return

    if hand_keeps_moving_but_item_falls_behind(
        previous_hand_block_box, B.box, hand_move
    ):
        # B 是 A 放下后重新看到的框；其位置就是本次整理的终点。
        confirm_rearrange(item, B.box, current_foods)


def try_confirm_full_item_placed(item, hand, current_foods):
    """
    完全遮挡时看不到 A 本身：手仍在移动、手附近突然出现一个库存中未认领的物品，
    且它能与 A 当前 track 估计框严格对应时，认为 A 被放下。
    """
    if not item.hold_and_move or not item.track:
        return

    expected_box = item.track[-1]
    for D in current_foods:
        # 此处对应前文“与手框贴着突然多了一个物品”，不是被手压住的物品。
        if not hand_is_near(hand, D.box):
            continue
        # 整理终点排除：只用严格匹配认定 D 已属于另一件旧库存物品。
        if any(
            other.item_id != item.item_id and strict_match(other, D)
            for other in item_by_id.values()
        ):
            continue
        if box_near(D.box, expected_box) and box_shape_strict_match(D.box, expected_box):
            confirm_rearrange(item, D.box, current_foods)
            return


def confirm_rearrange(item, release_box, current_foods):
    """在工作库存中确认 A 的新位置；后续帧立刻使用该位置继续判断。"""
    before_box = item.box
    item.box = release_box
    item.base_box = release_box
    item.status = VISIBLE
    item.release_box = release_box

    update_block_ids_as_front(item)
    emit_working_event("MOVED", item, before_box=before_box, after_box=release_box)

    # A 盖住 B 时，这里会使 B 变成【遮挡】；
    # A 再移开时，旧 block_id 被删掉，B 被匹配到后会重新变成【可见】。
    refresh_normal_occlusion(current_foods)
    clear_item_hand_transient_after_final_action(item)


def clear_item_hand_transient_after_final_action(item):
    item.shelter_or_hold = False
    item.hold_and_move = False
    item.hold_evidence_count = 0
    item.not_hold_evidence_count = 0
    item.first_hand_block_box = None
    item.last_hand_block_box = None
    item.move_values.clear()
    item.track.clear()
    item.hand_track_start_index = None
    hand_partial_blocked_ids.discard(item.item_id)
    hand_full_blocked_ids.discard(item.item_id)
```

## 6. 第一批/非第一批疑似入库物品，以及确认入库

```python
def update_first_batch_suspects(current_foods):
    """
    前文的特殊规则：第一帧随手进来的候选，若第 2、3 帧都无法继续匹配，
    就认为它已随手离开本次画面；只删除“疑似”记录，不产生库存 OUT 事件。
    """
    for S in list(suspected_new_items):
        if not S.first_batch:
            continue

        D = unique_detection_near_box(S.last_box, S.cls_id, current_foods)
        if D is not None:
            S.last_box = D.box
            S.missing_after_entry_frames = 0
        else:
            S.missing_after_entry_frames += 1
            if S.missing_after_entry_frames >= 2:
                suspected_new_items.remove(S)


def suspected_item_is_put_down(S, D, hand) -> bool:
    """
    只表达前文的业务条件：新物品不再继续随手移动，或手已经离开。
    具体“掉队/放下”的阈值和旧物品整理保持同一套判断。
    """
    return hand is None or (
        not hand_is_near(hand, D.box)
        and not hand_has_meaningful_overlap(hand, D.box)
    )


def confirm_in(S, D):
    global next_item_id

    new_item = InventoryItem()
    new_item.item_id = next_item_id
    next_item_id += 1
    new_item.cls_id = D.cls_id
    new_item.box = D.box
    new_item.base_box = D.box
    new_item.status = VISIBLE
    new_item.block_ids = set()

    # 新物品先进入工作库存，立刻参与本次手操作后续帧的匹配和遮挡计算。
    item_by_id[new_item.item_id] = new_item
    update_block_ids_as_front(new_item)
    emit_working_event("IN", new_item)
    suspected_new_items.remove(S)


def try_confirm_in(current_foods, hand):
    """
    只有同时满足以下条件才入库：
    - D 来自 suspected_new_item；
    - D 不能匹配任一旧库存物品；
    - D 也不是某个 hold_and_move 旧物品放下后的终点；
    - D 已经被放下（或手已经离开）。

    这样“第一帧手边看到的旧物品”不会被误入库。
    """
    for S in list(suspected_new_items):
        D = unique_detection_near_box(S.last_box, S.cls_id, current_foods)
        if D is None:
            continue
        # 入库候选排除：只用局部匹配识别可能已经存在的旧库存物品。
        if any(partial_match(item, D) for item in item_by_id.values()):
            continue
        if detection_matches_any_held_item(D):
            continue
        if suspected_item_is_put_down(S, D, hand):
            confirm_in(S, D)
```

## 7. 手离开：确认出库、补确认放下、清理本轮临时状态

```python
def detection_matches_any_box_on_track(item, current_foods) -> Detection | None:
    """前文的出库检查：在整个 track 路径上查找是否重新出现该物品。"""
    for estimated_box in reversed(item.track):
        D = unique_detection_near_box(estimated_box, item.cls_id, current_foods)
        if D is not None:
            return D
    return None


def entire_item_track_is_observable(item, current_foods) -> bool:
    """
    手离开后，检查 A 的旧位置和每个候选轨迹位置是否都足够可观察。

    item.track 的第一个框就是 A 的 base_box，因此旧位置也在检查范围内。
    这里保守地把当前快照中所有其他物品框都当作潜在遮挡物，
    复用《矩形动态遮挡问题说明.md》的 apply_cover() 逐个扣除。

    只要有一个候选位置被挡得太多，就返回 False；此时“没找到 A”
    不具备确认 OUT 的条件。这个函数只在手离开的收尾阶段调用，
    不会给每帧的实时处理增加大量计算。
    """
    if not item.track:
        return False

    for estimated_box in item.track:
        original_region = [bbox_to_box(estimated_box)]
        original_area = total_area(original_region)
        if original_area <= 0:
            return False

        remaining = original_region
        for D in current_foods:
            remaining, _ = apply_cover(
                remaining=remaining,
                new_cover=bbox_to_box(D.box),
            )

        observable_ratio = total_area(remaining) / original_area
        if observable_ratio < TRACK_POINT_OBSERVABLE_RATIO:
            return False

    return True


def confirm_out(item):
    # 只从工作库存删除；正式库存要等 commit_working_inventory() 才删除。
    # 记录出库前的完整对象，提交时用它确认这次缺失确实是 OUT。
    pending_out_by_id[item.item_id] = deep_copy(item)
    emit_working_event("OUT", item, before_box=item.box)
    remove_item_from_all_block_ids(item.item_id)
    del item_by_id[item.item_id]
    hand_partial_blocked_ids.discard(item.item_id)
    hand_full_blocked_ids.discard(item.item_id)


def finish_held_item_when_hand_left(item, current_foods):
    """
    收尾时不能把 hold_and_move=False 直接理解为“A 没有移动”。
    HAND_* 下的 False 可能只是本轮没凑齐两次有效正向证据。

    手离开后的无手快照提供最后一次强证据：
    - 旧位置看到 A：确认没有移动；
    - 轨迹的其他位置看到 A：补确认整理；
    - 整条轨迹都可观察却找不到 A：补确认出库；
    - 有任一候选位置仍被挡住：保持旧的工作库位置，不发 OUT。
    """
    A_at_old_position = find_A_at_old_position(item, current_foods)
    if A_at_old_position is not None:
        item.box = A_at_old_position.box
        reset_hand_state_to_visible(item)
        return

    # 无论之前是否已达到 hold_and_move=True，都查找整条候选轨迹。
    D = detection_matches_any_box_on_track(item, current_foods)
    if D is not None:
        confirm_rearrange(item, D.box, current_foods)
        return

    if entire_item_track_is_observable(item, current_foods):
        # 这是手离开后的强终局证据，可以补足过程中未达到 True 的情况。
        confirm_out(item)
        return

    # 轨迹存在不可观察区域，仍然无法分辨是否真正移动。
    # item.box/base_box 一直是进入本次 HAND_* 前的最后工作库位置，
    # 因此只清理本次手部临时状态即可，不需要回滚整个工作副本。
    reset_hand_state_to_visible(item)


def finish_hand_operation(current_foods):
    # 先让第一批疑似物品按第 2、3 帧规则更新，再决定谁是真正新物品。
    update_first_batch_suspects(current_foods)

    # 先完成旧库存中“疑似被手握住”的物品；它们优先于入库候选，
    # 避免把旧 A 的终点误当成新 B。
    affected_ids = list(hand_partial_blocked_ids | hand_full_blocked_ids)
    for item_id in affected_ids:
        item = item_by_id.get(item_id)
        if item is not None:
            finish_held_item_when_hand_left(item, current_foods)

    try_confirm_in(current_foods, hand=None)
    refresh_normal_occlusion(current_foods)

    # 到这里，本轮手操作的每一次整理/入库/出库已实时写入工作库存，且已完成本轮检查；
    # 手已经离开后，才把工作副本的最终结果提交到正式库存。
    commit_working_inventory()

    # 这一段连续有手操作结束；每个仍未成为入库物品的 suspect 也只属于本轮。
    suspected_new_items.clear()
    hand_track.clear()
    hand_partial_blocked_ids.clear()
    hand_full_blocked_ids.clear()
    remaining_item_ids.clear()
    released_hand_candidate_ids.clear()
```

## 8. 每一张 YOLO 输出的主流程

```python
def process_snapshot(current_snapshot):
    global previous_snapshot, old_hand

    hand = current_snapshot.hand
    current_foods = current_snapshot.foods

    if hand is None:
        if old_hand is not None:
            # 手刚离开：本帧就是“手离开后仍看不见/重新出现”的判断帧。
            finish_hand_operation(current_foods)
        # 没有手、也没有尚未结束的手操作时，不做入库、出库、整理推断。
        previous_snapshot = current_snapshot
        old_hand = None
        return

    # 当前帧有手。
    if old_hand is None:
        # 识别到手的第一帧。
        begin_hand_operation(hand, current_foods)
    else:
        hand_track.append(hand)
        frame_hand_delta = center(hand) - center(old_hand)
        # old_hand 是所有物品共用的上一帧手框；每个受手影响的物品
        # 各自保存这次位移，不能让物品之间共用同一个累计变量。
        append_frame_move_value_to_hand_affected_items(frame_hand_delta)
        update_first_batch_suspects(current_foods)

        if hand_has_explicit_move(hand, old_hand):
            process_moved_hand_frame(hand, frame_hand_delta, current_foods)
        else:
            # 手没有明确移动：不推断整理/入库/出库。
            # 只对待确认候选检查“旧位置仍是 A”的轻量反向证据，
            # 然后再把本帧新被手挡住的旧物品加入临时列表。
            update_pending_items_without_hand_move(current_foods)
            mark_newly_hand_blocked_items(hand, current_foods)

    previous_snapshot = current_snapshot
    old_hand = hand
```
