> IoM(A, B) = 面积(A ∩ B) / min(面积(A), 面积(B))


**严格匹配**:
1. [cls_id]是否一样
2. [中心位置的距离]是否足够小    <!-- 中心位置的距离越小, 说明两个框在空间位置上越接近 -->
3. [框高的差值]是否足够小
4. [框宽的差值]是否足够小       <!-- [框高的差值、框宽的差值]这两个都小, 说明两个框的大小形状越接近 -->



**局部匹配**:
1. [cls_id]是否一样
2. [IoM(A,B)] 是否足够接近 1    <!-- 公式越接近1, 说明两个框的越接近包含关系 (可能是A包含B, 或者B包含A) -->

**说明**
> 这个版本直接用每张 Yolo 输出的作为[快照]
> 库存的更新是: [当前快照]与[库存]进行比较的
> track的更新是: [当前快照]与[前一张快照]进行比较的 (当然也会用到库存的信息)

为了实现这个方法, 库存物品中要增加一些状体, 现在的状态有:【可见】、【遮挡】、【被手部分遮挡】、【被手完全遮挡】
其中:
    【遮挡】的物品其实还在原来的位置的, 只不过他现在看不见了而已(被其他物品挡住了)
    【整理中】的物品不在原来的位置了, 现在他去了其他位置(甚至有可能是出库了)


**明确几个逻辑**
1. 为了确认手是否有移动, 需要把[当前快照的] old_hand=hand 的信息保存记录下来，供后面使用

2. 手刚进来的时候必然只是遮挡了物品, 还没移动物品(按道理我们的算力应该允许这么快的频率), 这时后物品的变动其实很少的(大多都只是物体无意中被手碰到而导致的抖动或是yolo的抖动), 这时候这些被手遮挡了的物品的框我们也要去更新他们的box
    > 如果一个物品被手部分遮挡, 那么我们将这个物品的状态改为【被手部分遮挡】、A.shelter_or_hold=True, 并且更新记录这个物品的 hand_block_box (这时我们不要更新他的box; hand_block_box 就是这个物品上一时刻的box)
    > 如果一个物品被手完全遮挡, 那么我们将这个物品的状态改为【被手完全遮挡】、A.shelter_or_hold=True (这时我们不要更新他的box)

3. 手没有"明确"移动的话, 其实是没有发生任何变化的, 这时我们就不需要浪费算力去往后面算了(这时的变动只可能是yolo的抖动而已)

4. 如果手移动了的话, 我们就只需要处理那些之前被手遮挡了的物品就行了, 其他物品不需要浪费算力去算

5. 手移动了之后，我们要先算出这个[移动值](这个移动值包含了大小与方向了), 我们查看【被手部分遮挡】与【被手完全遮挡】的物体, 看看他们变得怎么样了(要通过这个检查来确认是不是真的被窝握住拿走了)
    > 对于【被手部分遮挡】的物体A, 我们用根据[移动值] 与 A.hand_block_box 推算出 hand_block_box_new (这个 hand_block_box_new 表示这个物体A如果是被手握住并且移动了的话, 那么他现在应该处于的位置就是大约为 hand_block_box_new, 并且他的框的形状与大小都是与 A.hand_block_box 差不多; 当然允许有一点误差)
        > 如果在[当前快照]的 hand_block_box_new 附近帧的找到一个与 A 有相同的 cls_id 的物品B, 并且物品B的形状大小与hand_block_box严格匹配, 并且物体A的原先位置(即:A.box) 看不到A了、并且物体A的原先位置并且没有没见过的物品。就说明A被手握住并且移动了, A.hold_and_move=True
        > 否者就说明这个物品A并不是被手握住移动的, A的状态变回【可见】, A.shelter_or_hold=False, A.hold_and_move=False
    > 对于【被手完全遮挡】的物体A, 就简单很多
        > 物体A的原先位置(即:A.box) 看不到A了、并且物体A的原先位置并且没有没见过的物品。这就说明A被手握住并且移动了, A.hold_and_move=True
        > 否者就说明这个物品A并不是被手握住移动的, A的状态变回【可见】, A.shelter_or_hold=False, A.hold_and_move=False
    


**注意**
这个[移动值]是要累计下来的, 只要连续有手就要一直累计。只有手没了之后才重置
而且这个[移动值]不能是一个公用的变量，而是应该是每一个【被手部分遮挡】、【被手完全遮挡】都应该各自持续保存更新的
因为有时候手是先晃一下然后再整理的，所以并不是一进来遮挡就只认为这几个是遮挡。手移动过程中，实时遮挡一个物品时都是要实时把这些物品改为【被手部分遮挡】或【被手完全遮挡】

**特别地**
如果一个物品A被手握住并且移动的话，这个物体A即便挡住其他物品C从而导致C看不见的话, 我们也是认为C是被手完全挡住
这样说的话, 我们要先处理那些被【被手部分遮挡】或【被手完全遮挡】
然后再来检查剩余的物品是否重新被遮挡, 这个顺序很重要
> 因此我们最好要维护3+1个辅助列表：1个用来存储【被手部分遮挡】的id, 1个用来存储【被手完全遮挡】的id, 1个用来存储剩余的id，还有一个用来实现用 item_id 映射到 item 的
> 这样就不需要一种 for 循环了, 能稍微快一点 (内存应该够, 3+1其实本质上也只是2个全量存储而已)


**有一个问题**
我们要思考一下我们这个每帧都检查对比的方法, 到底要怎么来实现物品的入库、出库与整理, 这才是最关键的内容
一个物品要入库, 必然是手拿进来, 一个物品出库也必然是手拿出去, 一个物品被整理移动也必然是通过手来实现
也就是说只要我们把手的操作处理干净、完美就行了。在手没进到冰箱(没事别到手)的时候, 其实我们不需要浪费算力、浪费心事去像这件事
既然入库、出库、整理都跟手有关, 那么我们就需要找到能将他们三个完美区分开来的方法

1. **入库**:
> 一个物品要想入库, 必然是手拿着这个物品进来, 进来的时候有可能这个新物品是完全被手挡住的, 也有可能这个新物品是露出了一部分出来
> 所以手刚进来的时候(**识别到手的第一帧**), 应该先检查手附近是否有识别到物品B (如果有的话, 这些物品B肯定是与手贴着的, 甚至或许有一点点重叠; 而且这时手附近的物体可能不止一个, 可能有多个的), 
    > 如果没有识别到物品B的话, 有可能是手完全挡住了新物品B, 也有可能是根本没有物品B (这时只是空手进来的)
        > 这时我们就不用额外的处理, 照常的去把检查库存中也没有被手挡住的物品 (有就将他们设置成【被手部分遮挡】或【被手完全遮挡】)
    > 如果有识别到物品B的话, 有可能这些物品B是新物品, 也有可能是旧物品
        > 我们先将这些物品B的信息全都保留下来(放到列表 suspected_new_item 中), 然后再去把检查库存中也没有被手挡住的物品 (有就将他们设置成【被手部分遮挡】或【被手完全遮挡】)

**要明确一个无法解决的情况**
由于我们是单摄像头, 有可能会出现在原本一个地方有一个物体A, 然后我们又拿进了一个一模一样的物体B(同 cls_id、框的形状大小也都一样), 然后这个物品B放置的地方从摄像头角度来看的话恰好跟物体A重合, 这中情况下我们是完全无法分辨出的 (除非手拿着这个物品进来的时候我们就已经看见有个物体进来了, 否者我们是解决不了这个问题的)
这种情况如果真的出现了, 我这里直接默认他没有放入新物品, 只是单纯的手进来晃动(在我们但摄像头、无重力传感器的情况下, 这时解决不了的)



2. **整理**:
> 一个物品要想被判断为整理, 必然是手拿着这个物品移动, 然后移动到某个位置后放下了
> 因此会出现的场景是：一个库存物品A原本看得见, 然后被手遮挡, 这时有可能是物体A被手部分遮挡(部分露出来看得见), 也有可能是物体A完全被手挡住了
> 如果物体A被手部分遮挡(部分露出来看得见)
    > 如果当手移动时, 这露出的部分也会跟着一起移动, 这样我们就知道这个物品是被手握住并移动的
    > 如果手在移动的过程中, 这露出的部分并不是同步的移动的话(具体来说:可见部分的大小形状发生了明显改变), 那么这个物品就不是被手握住并移动的, 只是被手遮挡了一段时间而已
> 如果物体A被手完全遮挡
    > 如果当手移动时, 物体依旧没有重新露出来被我们看到, 这样我们就知道这个物品是被手握住并移动的
    > 如果手在移动的过程中, 物体重新露出来被我们看到, 那么这个物品就不是被手握住并移动的, 只是被手遮挡了一段时间而已

**但是要注意一个问题**
> 手进来的时候有可能会挡住靠下面的物品, 但是这些物品可能只是被手挡住但没有握起并移动
> 但是手移动的过程中这些物品被手臂遮挡了, 而由于手臂的移动幅度不大, 有可能会一直挡住这个物品, 而这个物品只是被长时间挡住而并非是被手握住并移动
1. 从这个例子我们可以知道:**一个物品长时间被手遮挡时, 不要误把他当作是被握住了, 他有可能只是单纯的被长时间挡住了而已**

> 而且还有一个情况就是: 
> 有时候yolo识别手的时候, 可能不会把手臂完整框起来(可以有一部分手臂没框上), 这时如果手臂又把部分物体遮挡了, 从而会导致这些物品又没有手挡着、又看不见
(这不能通过修改yolo的数据集来实现, 因为如果整个手臂都要框住的话, 那么手进来的时候几乎把整个屏幕的一大半都遮挡了, 只有一小部分看得见了, 这样就相当于退化到静态快照对比了, 我们辛辛苦苦的换成逐帧对比的意义就没了)
2. 从这个例子我们可以知道:**一个物品被手完全挡住后, 当手移动后即便这个物品依旧看不见, 也不能说明这个物品是被手握住并移动**
所以说, 解决这个的方法是:
> 1. 当我们允许多个物品被怀疑是[被手握住并移动]
> 2. 识别到手的期间, 只处理【被手部分遮挡】与【被手完全遮挡】的物品, 以及处理手的框的这个部分。其他地方最好不要理(不理就不会错)
> 3. 但是我们拿到十分自信的证据的时候, 不要轻易的判断一个物品是[整理]到其他位置, 或[出库]
    > 对于【被手部分遮挡】的物体并且hold_and_move, 其实处理相对简单一点：因为他的框我们一直都可以看得见, 所以我们可以一直跟踪他的框的位置, 然后等都某一刻手一直在移动, 但是这个框移动的不如手移动的远(甚至没移动了), 也就是说这个物品"掉队了"，这时候用新的框与原来的框比较，看他的大小关系是不是包含关系，是的话就很大概率说明是这个物品放下了
    > 对于【被手部分遮挡】的物体并且hold_and_move, 其实处理也不难：这时由于他看不到物品是怎么动的，但是他看得到手是怎么动的, 所以我们可以一直跟踪手的框的位置, 然后等都某一刻手一直在移动, 但是这个手附近(与手的框贴着)突然多了一个物品，然后检查这个多了的物品是否能跟其他物品匹配，如果能的话就很大概率说明这个物品北方下了


3.**出库**
> 一个物品要想被判断为出库, 必然是手拿着这个物品移动, 然后直到手离开了也一直都没有放下, 并且最后手离开了也看不到这个物品重新出现

# .hand_block_box 属性
当一个库存物品被手部分遮挡时, 我们记录这个被收遮挡后, 我们看得到的这个物品的 box
这个物品在没被手遮挡是时的box我们依旧也是有的
这个 .hand_block_box 是只有【被手部分遮挡】才有值的, 其他状态的物品是空或none的 (无值)
而且这个 .hand_block_box 是在物体变成【被手部分遮挡】时才赋值一次, 后续都不会修改了; 除非他变回【可见】状态, 这时就清空.hand_block_box


# .move_value 属性
累计计算物体移动值, 只有【被手部分遮挡】或【被手完全遮挡】的物体才有值, 其他物体的值为0
手离开冰箱后(当前快照是别不到手), 时重置为0
状态从【被手部分遮挡】或【被手完全遮挡】变成其他状态时也重置为0


# .track 属性
记录物体(疑似)被手握住并移动时, 物体的在这个轨迹上的所有估计框
.track 是一个"队列", 每帧都将他的估计框的位置入到队尾
当一个物品被手握住并移动, 但是没有发现被方向来的时候, 看这个路径上有这个物品, 如果整条路径上都无法匹配上的话, 就说明出库了
一开始的位置也要输入 .track 中


# .block_ids 属性
> block_ids 只记录按照当前业务流程判断为位于目标物品前方, 并且与目标物品 base_box 存在有效交集的物品
> 因此, 后续使用 block_ids 中的物品进行 apply_cover 时, 可以直接把它们当作前方遮挡物
> **整理后重新放置的物品, 以及本轮确认入库的新物品, 都视为位于发生重叠的旧物品前方**
(.block_ids 不是一个数, 而是一个集合set, 他要允许记录多个物品信息记录, 而且能自动**去重**)


# suspected_new_item 列表
> 用来存储怀疑是新物品的列表
> 每次手进来的第一帧, 手附近与手贴着的物品B, 这些物品B会进入到这个列表
> 手移动后, 手原先的地方出现没见过的物品, 这些物品B会进入到这个列表
> 注意：suspected_new_item 要区分开[第一批]与[非第一批]
    > 这些第一帧就进来的这些物品B与之后进来的那些物品的操作有所不同
    > [第一批]的物品, 只需要他第二帧第三帧发现匹配不上这些物品后, 这些匹配不上的物品就出库了


# apply_cover 函数

> apply_cover 的作用、完整定义和判定条件见《矩形动态遮挡问题说明.md》

```python
class BBox:
    x1: float
    y1: float
    x2: float
    y2: float

    @property
    def w(self):
        return self.x2 - self.x1

    @property
    def h(self):
        return self.y2 - self.y1

    @property
    def cx(self):
        return (self.x1 + self.x2) / 2

    @property
    def cy(self):
        return (self.y1 + self.y2) / 2


class Vector:   # 坐标
    dx: float
    dy: float


class Detection:
    cls_id: int
    box: BBox
    score: float


class InitialInventoryCheckFailed(Exception):
    pass


def clear_session_runtime_state():
    """
    清理“本次开门/本段手操作”的临时状态, 但绝不清空跨关门保存的 inventory。

    如果上一次会话在手还存在时异常结束，库存中的 HAND_* 状态也不能带到下一次会话；
    这里只把它们恢复成普通 VISIBLE，后续再由当前帧重新判断遮挡关系。
    OCCLUDED、block_ids、item_id 和 base_box 都不在这里清除。
    """
    global previous_snapshot, old_hand

    previous_snapshot = None
    old_hand = None
    hand_track.clear()  # 清空手的轨迹
    suspected_new_items.clear()  # 清空可能的新物品
    hand_partial_blocked_ids.clear()
    hand_full_blocked_ids.clear()
    remaining_item_ids.clear()
    
    # 遍历所有库存物品
    for item in inventory_by_id.values():
```

```python
# 交集面积
def intersection_area(box_a, box_b) -> float:
    left = max(box_a.x1, box_b.x1)
    top = max(box_a.y1, box_b.y1)
    right = min(box_a.x2, box_b.x2)
    bottom = min(box_a.y2, box_b.y2)
    if right <= left or bottom <= top:
        return 0.0
    return (right - left) * (bottom - top)

# 面积
def box_area(box) -> float:
    return max(0.0, box.w) * max(0.0, box.h)

# IoM
def IoM(box_a, box_b) -> float:
    denominator = min(box_area(box_a), box_area(box_b))
    if denominator <= 0:
        return 0.0
    return intersection_area(box_a, box_b) / denominator

# 中心坐标
def center(box) -> Vector:
    return Vector(dx=box.cx, dy=box.cy)

# 中心距离
def center_distance(box_a, box_b) -> float:
    return sqrt((box_a.cx - box_b.cx) ** 2 + (box_a.cy - box_b.cy) ** 2)

# 对角线长度
def length(vector) -> float:
    return sqrt(vector.dx ** 2 + vector.dy ** 2)


def normalized_distance(box_a, box_b) -> float:
    # 用目标框的尺度归一化中心距离；具体归一化方式以后按画面标定。
    scale = max(min(box_a.w, box_a.h), 1.0)
    return center_distance(box_a, box_b) / scale

# 覆盖率
def cover_ratio(target, cover) -> float:
    target_area = box_area(target)
    if target_area <= 0:
        return 0.0
    return intersection_area(target, cover) / target_area

# 通过中心距离来判断两个框是否足够接近
def box_near(box_a, box_b) -> bool:
    return center_distance(box_a, box_b) <= BOX_NEAR_DISTANCE

# 严格匹配框的形状大小
def box_shape_strict_match(box_a, box_b) -> bool:
    return (
        abs(box_a.w - box_b.w) <= STRICT_WIDTH_DELTA
        and abs(box_a.h - box_b.h) <= STRICT_HEIGHT_DELTA
    )

# 总面积
def total_area(regions) -> float:
    return sum(box_area(region) for region in regions)


def apply_cover(remaining_regions, cover_box) -> list[BBox]:
    """
    从 remaining_regions 中扣除 cover_box 与每个矩形的交集，返回剩余矩形。
    一个矩形被切开时可以返回上、下、左、右多个矩形；重复区域不能重复计面积。
    这里是《矩形动态遮挡问题说明.md》中 apply_cover 的伪代码接口。
    """
    next_regions = []
    for region in remaining_regions:
        next_regions.extend(rectangle_subtract(region, cover_box))
    return next_regions


def rectangle_subtract(region, cover_box) -> list[BBox]:
    """返回 region - cover_box 的非空矩形分块。"""
    ix1 = max(region.x1, cover_box.x1)
    iy1 = max(region.y1, cover_box.y1)
    ix2 = min(region.x2, cover_box.x2)
    iy2 = min(region.y2, cover_box.y2)

    if ix2 <= ix1 or iy2 <= iy1:
        return [region]

    pieces = [
        BBox(region.x1, region.y1, region.x2, iy1),  # 上
        BBox(region.x1, iy2, region.x2, region.y2),  # 下
        BBox(region.x1, iy1, ix1, iy2),               # 左
        BBox(ix2, iy1, region.x2, iy2),               # 右
    ]
    return [piece for piece in pieces if box_area(piece) > 0]
```

## 1. 基础匹配、框和遮挡函数

```python
def strict_box_match(left_cls, left_box, right_cls, right_box) -> bool:
    """前文的严格匹配：类别相同，中心、宽、高都足够接近。"""
    return (
        left_cls == right_cls
        and center_distance(left_box, right_box) <= STRICT_CENTER_DISTANCE
        and abs(left_box.w - right_box.w) <= STRICT_WIDTH_DELTA
        and abs(left_box.h - right_box.h) <= STRICT_HEIGHT_DELTA
    )


def strict_match(left, right) -> bool:
    return strict_box_match(left.cls_id, left.box, right.cls_id, right.box)


def partial_match(left, right) -> bool:
    """前文的局部匹配：类别相同，IoM 接近 1。"""
    return left.cls_id == right.cls_id and IoM(left.box, right.box) >= PARTIAL_IOM


def hand_touches_or_near(hand_box, object_box) -> bool:
    return (
        intersection_area(hand_box, object_box) >= HAND_TOUCH_AREA
        or normalized_distance(hand_box, object_box) <= HAND_NEAR_DISTANCE
    )


def hand_fully_covers(hand_box, object_box) -> bool:
    return cover_ratio(target=object_box, cover=hand_box) >= HAND_FULL_COVER_RATIO


def hand_has_explicit_move(hand_box, old_hand_box) -> bool:
    # 小抖动不算“明确移动”。
    return center_distance(hand_box, old_hand_box) >= HAND_MOVE_DISTANCE


def move_box(box, move_value) -> BBox:
    return BBox(
        x1=box.x1 + move_value.dx,
        y1=box.y1 + move_value.dy,
        x2=box.x2 + move_value.dx,
        y2=box.y2 + move_value.dy,
    )


def unique_detection_matching_item(item, detections) -> Detection | None:
    """
    在当前帧中寻找能唯一对应 item 的 Detection。
    先严格匹配；没有时才允许局部匹配。
    有多个同样可能的结果时返回 None，不能把同一个框分给多个 item。
    """
    candidates = [D for D in detections if strict_match(item, D)]
    if len(candidates) == 1:
        return candidates[0]

    candidates = [D for D in detections if partial_match(item, D)]
    return candidates[0] if len(candidates) == 1 else None


def unique_detection_near_box(expected_box, cls_id, detections) -> Detection | None:
    """寻找类别相同、位置在 expected_box 附近且框大小形状严格匹配的唯一 Detection。"""
    candidates = []
    for D in detections:
        if D.cls_id != cls_id:
            continue
        if box_near(D.box, expected_box) and box_shape_strict_match(D.box, expected_box):
            candidates.append(D)
    return candidates[0] if len(candidates) == 1 else None


def suspect_matches_detection(suspect, detection) -> bool:
    return strict_box_match(suspect.cls_id, suspect.last_box,
                            detection.cls_id, detection.box)


def detection_matches_any_inventory_item(D) -> bool:
    return any(
        strict_match(item, D) or partial_match(item, D)
        for item in item_by_id.values()
    )


def detection_matches_other_inventory_item(D, except_item_id) -> bool:
    return any(
        item.item_id != except_item_id
        and (strict_match(item, D) or partial_match(item, D))
        for item in item_by_id.values()
    )


def detection_matches_any_held_item(D) -> bool:
    for item_id in hand_partial_blocked_ids | hand_full_blocked_ids:
        item = item_by_id.get(item_id)
        if item is None or not item.hold_and_move or not item.track:
            continue
        if box_near(D.box, item.track[-1]) and box_shape_strict_match(D.box, item.track[-1]):
            return True
    return False


def old_position_is_clean(item, detections) -> bool:
    """
    对应前文的两个条件：
    1. item 原来的 A.box 位置已经看不到 A；
    2. A 原位置没有一个“没见过的物品”。
    """
    for D in detections:
        if strict_match(item, D) or partial_match(item, D):
            return False
        if intersection_area(item.box, D.box) > OLD_POSITION_OVERLAP:
            # D 不能对应 A，却占据 A 原位置；它是“没见过的物品”。
            return False
    return True


def is_fully_covered(item) -> bool:
    remaining = [item.base_box]
    for front_item_id in item.block_ids:
        front_item = item_by_id.get(front_item_id)
        if front_item is not None:
            remaining = apply_cover(remaining, front_item.base_box)
    return total_area(remaining) <= COVER_REMAINING_AREA_EPS
```

## 2. `block_ids` 与普通遮挡状态

```python
def remove_item_from_all_block_ids(item_id):
    for item in item_by_id.values():
        item.block_ids.discard(item_id)


def update_block_ids_as_front(front_item):
    """
    前文规定：确认整理后重新放下的物品、确认入库的新物品，
    如果与旧物品 base_box 相交，都视为位于旧物品前方。
    """
    remove_item_from_all_block_ids(front_item.item_id)

    for target in item_by_id.values():
        if target.item_id == front_item.item_id:
            continue
        if intersection_area(target.base_box, front_item.base_box) > BLOCK_OVERLAP_AREA_EPS:
            target.block_ids.add(front_item.item_id)


def refresh_normal_occlusion(current_foods):
    """
    这里只处理普通【遮挡】和【可见】，不处理被手遮挡的物品。
    由确认放下/确认入库，或手离开后调用。
    """
    for item in item_by_id.values():
        if item.status in {HAND_PARTIAL_BLOCKED, HAND_FULL_BLOCKED}:
            continue

        D = unique_detection_matching_item(item, current_foods)

        if D is not None:
            # 看得到时，先更新当前 box；base_box 只在确认整理时换位置。
            item.box = D.box
            if item.status == OCCLUDED and not is_fully_covered(item):
                item.status = VISIBLE
                emit_event("REVEALED", item)
            continue

        # 当前没检测到 item，只有被 block_ids 的前方物品完整盖住时，
        # 才把它变为普通【遮挡】。
        if item.status == VISIBLE and is_fully_covered(item):
            item.status = OCCLUDED
            emit_event("OCCLUDED", item)
```

```python
def begin_hand_operation(hand, current_foods):

    # 必须在记录第一批疑似新物品之后，再检查库存中哪些旧物品被手遮挡。

def enter_hand_partial_blocked(item, hand, visible_detection):
    item.status = HAND_PARTIAL_BLOCKED
    item.shelter_or_hold = True
    item.hold_and_move = False

    # 进入状态时只赋值一次；后续不再改 hand_block_box，也不改 item.box。
    # 按前文“上一时刻的 box”，优先使用上一帧能对应 A 的框；没有时用 A.box。
    previous_D = (
        unique_detection_matching_item(item, previous_snapshot.foods)
        if previous_snapshot is not None else None
    )
    item.hand_block_box = previous_D.box if previous_D is not None else item.box
    item.last_partial_box = visible_detection.box
    item.move_value = Vector(0, 0)
    item.last_hand_box = hand
    item.track = deque([item.base_box])

    hand_partial_blocked_ids.add(item.item_id)
    hand_full_blocked_ids.discard(item.item_id)
    remaining_item_ids.discard(item.item_id)


def enter_hand_full_blocked(item, hand):
    item.status = HAND_FULL_BLOCKED
    item.shelter_or_hold = True
    item.hold_and_move = False
    item.hand_block_box = None
    item.last_partial_box = None
    item.move_value = Vector(0, 0)
    item.last_hand_box = hand
    item.track = deque([item.base_box])

    hand_full_blocked_ids.add(item.item_id)
    hand_partial_blocked_ids.discard(item.item_id)
    remaining_item_ids.discard(item.item_id)


def mark_newly_hand_blocked_items(hand, current_foods):
    """
    只检查尚未被处理的旧库存物品。
    原本处于普通【遮挡】的物品不在这里当作新的手遮挡候选。
    """
    remaining_item_ids.clear()
    remaining_item_ids.update(item_by_id.keys())
    remaining_item_ids -= hand_partial_blocked_ids
    remaining_item_ids -= hand_full_blocked_ids

    for item_id in list(remaining_item_ids):
        item = item_by_id[item_id]
        if item.status == OCCLUDED:
            continue

        D = unique_detection_matching_item(item, current_foods)
        if D is not None and hand_touches_or_near(hand, D.box):
            enter_hand_partial_blocked(item, hand, D)
        elif D is None and hand_fully_covers(hand, item.base_box):
            enter_hand_full_blocked(item, hand)
```

## 4. 手移动时：先处理已有被手遮挡物品，再处理新遮挡物品

```python
def add_item_move_value(item, current_hand) -> float:
    """每个 item 自己累计 move_value；它不是所有物品共用的变量。"""
    hand_delta = center(current_hand) - center(item.last_hand_box)
    item.move_value += hand_delta
    item.last_hand_box = current_hand
    return length(hand_delta)


def append_estimated_track_box(item):
    # track 的每个点始终是完整物品的估计框，不直接把局部 Detection 当完整框。
    item.track.append(move_box(item.base_box, item.move_value))


def reset_hand_state_to_visible(item):
    """前文中“不是被手握住移动”的回退操作。"""
    item.status = VISIBLE
    item.shelter_or_hold = False
    item.hold_and_move = False
    item.hand_block_box = None
    item.move_value = Vector(0, 0)
    item.track.clear()
    item.last_hand_box = None
    item.last_partial_box = None
    item.release_box = None
    hand_partial_blocked_ids.discard(item.item_id)
    hand_full_blocked_ids.discard(item.item_id)


def update_partially_hand_blocked_item(item, hand, current_foods):
    """
    对应前文：用 A.hand_block_box + A.move_value 推出 hand_block_box_new，
    在当前快照中寻找同类、形状大小严格匹配的 B。
    """
    hand_move = add_item_move_value(item, hand)
    expected_partial_box = move_box(item.hand_block_box, item.move_value)
    B = unique_detection_near_box(expected_partial_box, item.cls_id, current_foods)

    if B is None or not old_position_is_clean(item, current_foods):
        reset_hand_state_to_visible(item)
        return

    item.hold_and_move = True
    append_estimated_track_box(item)

    # 物品仍能看见时，保留当前局部框，仅用于下一帧比较“物品是否掉队”。
    previous_partial_box = item.last_partial_box
    item.last_partial_box = B.box
    try_confirm_partial_item_placed(item, previous_partial_box, B, hand_move, current_foods)


def update_fully_hand_blocked_item(item, hand, current_foods):
    """
    对应前文的完全遮挡规则：原位置既看不到 A，也没有未知物品时，
    记录为 hold_and_move 候选；这一步还不直接宣布整理或出库。
    """
    add_item_move_value(item, hand)

    if not old_position_is_clean(item, current_foods):
        reset_hand_state_to_visible(item)
        return

    item.hold_and_move = True
    append_estimated_track_box(item)
    try_confirm_full_item_placed(item, hand, current_foods)


def collect_non_first_batch_suspected_new_items(old_hand, current_foods):
    """
    手移动后，手原先的位置出现一个库存中没有见过的物品时，加入非第一批。
    """
    for D in current_foods:
        if not hand_touches_or_near(old_hand, D.box):
            continue
        if detection_matches_any_inventory_item(D):
            continue
        if detection_matches_any_held_item(D):
            continue
        append_suspected_new_item(D, first_batch=False)


def process_moved_hand_frame(hand, current_foods):
    """
    顺序不能交换：
    1. 先处理上一时刻已被手部分/完全遮挡的 item；
    2. 再处理手移动后新出现的疑似入库物品；
    3. 最后才检查剩余 item 是否在这一帧新被手遮挡。
    """
    for item_id in list(hand_partial_blocked_ids):
        item = item_by_id.get(item_id)
        if item is not None:
            update_partially_hand_blocked_item(item, hand, current_foods)

    for item_id in list(hand_full_blocked_ids):
        item = item_by_id.get(item_id)
        if item is not None:
            update_fully_hand_blocked_item(item, hand, current_foods)

    collect_non_first_batch_suspected_new_items(old_hand, current_foods)
    mark_newly_hand_blocked_items(hand, current_foods)
```

## 5. 确认“放下”并完成整理

```python
def hand_keeps_moving_but_item_falls_behind(previous_partial_box, current_box, hand_move) -> bool:
    """
    前文中“手一直在移动，但物品框移动得不如手远、甚至不动”的条件。
    同时要求前后局部框仍满足包含/局部关系，排除完全不同的 Detection。
    """
    if previous_partial_box is None:
        return False

    item_move = center_distance(current_box, previous_partial_box)
    return (
        hand_move >= HAND_MOVE_DISTANCE
        and item_move <= hand_move * ITEM_FALL_BEHIND_RATIO
        and IoM(previous_partial_box, current_box) >= PARTIAL_IOM
    )


def try_confirm_partial_item_placed(item, previous_partial_box, B, hand_move, current_foods):
    if not item.hold_and_move:
        return

    if hand_keeps_moving_but_item_falls_behind(previous_partial_box, B.box, hand_move):
        # B 是 A 放下后重新看到的框；其位置就是本次整理的终点。
        confirm_rearrange(item, B.box, current_foods)


def try_confirm_full_item_placed(item, hand, current_foods):
    """
    完全遮挡时看不到 A 本身：手仍在移动、手附近突然出现一个库存中未认领的物品，
    且它能与 A 当前 track 估计框严格对应时，认为 A 被放下。
    """
    if not item.hold_and_move or not item.track:
        return

    expected_box = item.track[-1]
    for D in current_foods:
        if not hand_touches_or_near(hand, D.box):
            continue
        if detection_matches_other_inventory_item(D, except_item_id=item.item_id):
            continue
        if box_near(D.box, expected_box) and box_shape_strict_match(D.box, expected_box):
            confirm_rearrange(item, D.box, current_foods)
            return


def confirm_rearrange(item, release_box, current_foods):
    """确认 A 已被放到一个新位置；该位置的 A 位于所有发生重叠的旧物品前方。"""
    before_box = item.box
    item.box = release_box
    item.base_box = release_box
    item.status = VISIBLE
    item.release_box = release_box

    update_block_ids_as_front(item)
    emit_event("MOVED", item, before_box=before_box, after_box=release_box)

    # A 盖住 B 时，这里会使 B 变成【遮挡】；
    # A 再移开时，旧 block_id 被删掉，B 被匹配到后会重新变成【可见】。
    refresh_normal_occlusion(current_foods)
    clear_item_hand_transient_after_final_action(item)


def clear_item_hand_transient_after_final_action(item):
    item.shelter_or_hold = False
    item.hold_and_move = False
    item.hand_block_box = None
    item.move_value = Vector(0, 0)
    item.track.clear()
    item.last_hand_box = None
    item.last_partial_box = None
    hand_partial_blocked_ids.discard(item.item_id)
    hand_full_blocked_ids.discard(item.item_id)
```

## 6. 第一批/非第一批疑似入库物品，以及确认入库

```python
def update_first_batch_suspects(current_foods):
    """
    前文的特殊规则：第一帧随手进来的候选，若第 2、3 帧都无法继续匹配，
    就认为它已随手离开本次画面；只删除“疑似”记录，不产生库存 OUT 事件。
    """
    for S in list(suspected_new_items):
        if not S.first_batch:
            continue

        D = unique_detection_near_box(S.last_box, S.cls_id, current_foods)
        if D is not None:
            S.last_box = D.box
            S.missing_after_entry_frames = 0
        else:
            S.missing_after_entry_frames += 1
            if S.missing_after_entry_frames >= 2:
                suspected_new_items.remove(S)


def suspected_item_is_put_down(S, D, hand) -> bool:
    """
    只表达前文的业务条件：新物品不再继续随手移动，或手已经离开。
    具体“掉队/放下”的阈值和旧物品整理保持同一套判断。
    """
    return hand is None or not hand_touches_or_near(hand, D.box)


def confirm_in(S, D):
    global next_item_id

    new_item = InventoryItem()
    new_item.item_id = next_item_id
    next_item_id += 1
    new_item.cls_id = D.cls_id
    new_item.box = D.box
    new_item.base_box = D.box
    new_item.status = VISIBLE
    new_item.block_ids = set()

    inventory_by_id[new_item.item_id] = new_item
    update_block_ids_as_front(new_item)
    emit_event("IN", new_item)
    suspected_new_items.remove(S)


def try_confirm_in(current_foods, hand):
    """
    只有同时满足以下条件才入库：
    - D 来自 suspected_new_item；
    - D 不能匹配任一旧库存物品；
    - D 也不是某个 hold_and_move 旧物品放下后的终点；
    - D 已经被放下（或手已经离开）。

    这样“第一帧手边看到的旧物品”不会被误入库。
    """
    for S in list(suspected_new_items):
        D = unique_detection_near_box(S.last_box, S.cls_id, current_foods)
        if D is None:
            continue
        if detection_matches_any_inventory_item(D):
            continue
        if detection_matches_any_held_item(D):
            continue
        if suspected_item_is_put_down(S, D, hand):
            confirm_in(S, D)
```

## 7. 手离开：确认出库、补确认放下、清理本轮临时状态

```python
def detection_matches_any_box_on_track(item, current_foods) -> Detection | None:
    """前文的出库检查：在整个 track 路径上查找是否重新出现该物品。"""
    for estimated_box in reversed(item.track):
        D = unique_detection_near_box(estimated_box, item.cls_id, current_foods)
        if D is not None:
            return D
    return None


def confirm_out(item):
    emit_event("OUT", item, before_box=item.box)
    remove_item_from_all_block_ids(item.item_id)
    del inventory_by_id[item.item_id]
    hand_partial_blocked_ids.discard(item.item_id)
    hand_full_blocked_ids.discard(item.item_id)


def finish_held_item_when_hand_left(item, current_foods):
    """
    出库只有在：A 已经 hold_and_move、没有发现放下、手离开后也没有重新出现时确认。
    """
    if not item.hold_and_move:
        # 只是被手遮挡而没有确认移动：按前文恢复为【可见】，不判 OUT。
        D = unique_detection_matching_item(item, current_foods)
        if D is not None:
            item.box = D.box
        reset_hand_state_to_visible(item)
        return

    # 完全遮挡期间没有看到放下时，手离开后的第一张无手快照还能补确认整理。
    D = detection_matches_any_box_on_track(item, current_foods)
    if D is not None:
        confirm_rearrange(item, D.box, current_foods)
    else:
        confirm_out(item)


def finish_hand_operation(current_foods):
    # 先让第一批疑似物品按第 2、3 帧规则更新，再决定谁是真正新物品。
    update_first_batch_suspects(current_foods)

    # 先完成旧库存中“疑似被手握住”的物品；它们优先于入库候选，
    # 避免把旧 A 的终点误当成新 B。
    affected_ids = list(hand_partial_blocked_ids | hand_full_blocked_ids)
    for item_id in affected_ids:
        item = item_by_id.get(item_id)
        if item is not None:
            finish_held_item_when_hand_left(item, current_foods)

    try_confirm_in(current_foods, hand=None)
    refresh_normal_occlusion(current_foods)

    # 这一段连续有手操作结束；每个仍未成为入库物品的 suspect 也只属于本轮。
    suspected_new_items.clear()
    hand_track.clear()
    hand_partial_blocked_ids.clear()
    hand_full_blocked_ids.clear()
    remaining_item_ids.clear()
```

## 8. 每一张 YOLO 输出的主流程

```python
def process_snapshot(current_snapshot):
    global previous_snapshot, old_hand

    hand = current_snapshot.hand
    current_foods = current_snapshot.foods

    if hand is None:
        if old_hand is not None:
            # 手刚离开：本帧就是“手离开后仍看不见/重新出现”的判断帧。
            finish_hand_operation(current_foods)
        # 没有手、也没有尚未结束的手操作时，不做入库、出库、整理推断。
        previous_snapshot = current_snapshot
        old_hand = None
        return

    # 当前帧有手。
    if old_hand is None:
        # 识别到手的第一帧。
        begin_hand_operation(hand, current_foods)
    else:
        hand_track.append(hand)
        update_first_batch_suspects(current_foods)

        if hand_has_explicit_move(hand, old_hand):
            process_moved_hand_frame(hand, current_foods)
        else:
            # 手没有明确移动：不推断整理/入库/出库；
            # 仅允许把这一帧新被手挡住的旧物品加入临时列表。
            mark_newly_hand_blocked_items(hand, current_foods)

    previous_snapshot = current_snapshot
    old_hand = hand
```

## 9. A 遮挡 B、再移开露出 B 的最小闭环

```python
# 初始：A、B 都是 VISIBLE，且 A、B 各自有自己的 base_box。

# 1. 手碰到 A，A 进入 HAND_PARTIAL_BLOCKED 或 HAND_FULL_BLOCKED。
#    此时 A.box 不改，A.hand_block_box / A.move_value / A.track 开始记录。

# 4. 当前快照重新看到 B：
#    refresh_normal_occlusion() 匹配 B，且 apply_cover 后 B 仍有可见区域
```
