snapshot	            快照，一段时间内 YOLO 多帧投票后的物品列表
baseline_snapshot	    基准快照，上一次已经完成库存裁决的稳定快照
current_snapshot	    当前刚生成的新快照
contrast_snapshot	    对照快照，用来判断画面是否稳定
stable_snapshot	        新确认的无手稳定快照，可以拿来做库存判断
diff_snapshots	        对比两份快照，判断库存变化


可以理解成：
    baseline_snapshot = 旧稳定画面
    stable_snapshot   = 新稳定画面
    diff_snapshots    = 比较旧画面和新画面发生了什么
-------------------------------------------------------------------------------



item	                库存物品
item_id	                物品唯一编号，比如 item#5
class_id / cls_id	    类别编号，比如 apple、orange 的类别 ID
class_name	            类别名称
bbox	                检测框，物品在画面里的矩形位置
old_bbox	            旧位置框
new_bbox	            新位置框
last_visible_bbox	    最近一次可见时的位置
score	                YOLO 检测置信度
track_id	            ByteTrack 分配的临时轨迹 ID


bbox 就是这种：
    (x1, y1) ~ (x2, y2)
-------------------------------------------------------------------------------



relocation	                整理 / 移动
relocation_match	        判断某个旧物品是不是移动到了新位置
relocation settlement	    整理结算，先处理被移动过的物品
RelocationCandidate	        整理候选
PendingRelocation	        待确认整理
pending_relocation	        证据不够强，先冻结，等下一份稳定快照确认
confirmed_relocation	    确认整理
low_confidence_relocation	低置信整理
no_relocation	            不是整理


这里最重要的是：
    relocation = 整理/移动
    pending = 暂时不确定，先等一等
    confirmed = 确认
-------------------------------------------------------------------------------



OperationContext	    操作上下文，记录两份稳定快照之间发生过什么
operation_context	    当前这一轮的操作证据
operation_locked	    被操作锁定，本轮优先判断整理，不先当作普通物品
operation_locked_items	被手碰过、HELD 过、或移动过的物品集合
touched_item_ids	    被手碰到过的物品 ID
hand_seen	            是否看到过手
hand_present	        当前快照/帧是否有手
hand_long_present	    手是否停留较久


operation_locked 可以理解成：
    这个物品本轮可能被操作过，先别急着说它没动。
-------------------------------------------------------------------------------



HELD	                被手遮挡/拿住后的临时证据
candidate_held_items	可能被手遮挡的物品
confirmed_held_items	已确认被手遮挡后持续不可见的物品
HeldProxyEvidence	    手代理轨迹证据
held_proxy_evidences	所有手代理轨迹证据
proxy_trajectory	    代理轨迹，用手的位置推测物品移动路径


它只是说：
    这个物品被手挡住了，物品自己的轨迹断了。
    先用手的轨迹临时代替它的轨迹。
-------------------------------------------------------------------------------



same_position_objects	原位置还在的物品
disappeared_objects	    旧快照有，新快照原位置没了的物品
appeared_objects	    新快照多出来的物品
consumed	            已被某个事件使用掉
settled	                已经结算完成
pending_reserved	    被 pending 占用，暂时不能判放入/出库


最关键的一组：
    same_position_objects = 看起来还在原位
    disappeared_objects   = 看起来消失了
    appeared_objects      = 看起来新出现了
----------------------------------------------------------------------------




snapshot_cluster_match	 快照内部聚合匹配
strict_origin_match	     原位严格匹配
reid_match	             外观重识别匹配
reid_score	             外观相似分数
track_score	             轨迹证据分数
held_score	             HELD 证据分数
hand_score	             手部操作证据分数
negative_score	         反证分数
total_score	             综合分数

简单理解：
    strict_origin_match = 判断是不是还在原位置
    reid_match          = 判断两个物品看起来像不像
    relocation_match    = 判断是不是整理到了新位置
--------------------------------------------------------------------------



ByteTrack	            目标跟踪算法
TrackEvidence	        轨迹证据
active_track_evidences	当前活跃轨迹证据
moving_tracks	        发生明显移动的轨迹
moved_item_candidates	可能被移动过的库存物品
start_bbox	            轨迹起点框
end_bbox	            轨迹终点框
trajectory_points	    轨迹点列表
lost_frame_count	    轨迹丢失帧数
