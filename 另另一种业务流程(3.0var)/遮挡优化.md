**个人理解**
1. 有物品入库时
当物品A入库的时候, 与工作库存中的所有物品进行检查, 看那些与物品A的box有重叠的（交集大于0）(可能有多个物品被遮挡的, 我这里为了方便统称为物品B)，这些物品B 的 B.block_id.append(A.item_id)

然后从这些物品B找出其中的【可见】状态的物品, 计算这些物品是否被完全遮挡(即他露出的面积为0)， 如果是的话，就说明从【可见】变成【遮挡】，判断为遮挡

伪代码:
```python
for B in 工作库存中的物品:   # 注意使用的是工作库存中的物品
    if B.base_box 与 A.base_box 有重叠(有交集):
        B.block_id.append(A.item_id)

        if B 的状态是【可见】:
            remaining=normalize_box(B.base_box)   # 注意使用的是 base_box
            for item_id in B.block_id:  
                new_cover=normalize_box(获取 item_id 的 base_box)   # 注意使用的是 base_box
                remaining, _ = apply_cover(remaining=remaining, new_cover=new_cover)
                    if remaining.area ≤ eps_area:
                        break
            if remaining.area ≤ eps_area:
                # 说明B被完全遮挡
                B的状态变成【遮挡】
                处理后续的操作...
```
