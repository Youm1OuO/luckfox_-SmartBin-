# 细节15：处理间接移动的旧物品，避免大位移未决卡住

## 目标

一次手操作中，手直接移动 A 时，旁边旧物品 B/C 可能被碰撞、推挤或滚动而移动；
它们未必被手框覆盖。当前逻辑会在 B/C 的检测框偏移较小时按静态收尾、偏移达到
正式 MOVED 门槛后又因没有直接手持证据而保持未决，最终阻塞整轮提交。

下一次修改要补上**间接移动旧物品**的确认链：能可靠确认时更新其位置并正常结算；
身份唯一且观测稳定时必须收敛，真正缺少身份信息时不能猜测。

## 必须保留的现有能力

不得改动全局 YOLO/NMS、手覆盖、移动距离、匹配或确认帧数阈值。尤其必须保持：

- 正常直接拿取/推动的 IN、OUT、MOVED、遮挡和恢复流程；
- 细节9至细节14的同类一对一认领、claim grace、C-D alias 与 D 防误确认；
- 细节14的短暂假 D 不能借静态旧 C 证据确认；
- 真实同类新物品仍可按现有 D 链路入库；
- 同类身份不清时保持未决，不能按 item_id 或就近规则硬分配。

不得仅通过调大 `FLOW3_COMMIT_MOVE_CENTER_DISTANCE`，或把超过该门槛的框一律当作
静态，来消除本问题。

## 业务结论

对操作开始前已经存在的旧物品 B/C，必须区分三种结果：

```text
有可靠间接移动证据
    -> 确认其新位置；更新 base_box。
    -> 若位移仍达到既有正式 MOVED 门槛，产生 MOVED。
    -> 若位移较小，只更新位置，不额外制造 MOVED 事件。

没有可靠移动证据，但有连续、唯一、稳定的直接无手检测框
    -> 作为稳定观察重同步位置，解除未决；不产生 MOVED。
    -> 这条只用于抵御密集摆放造成的 YOLO 框边界偏移。

同类身份竞争、合并框、漏检或证据不连续
    -> 保持 UNRESOLVED，不能猜测 MOVED/OUT/IN。
```

第二条不能只凭一帧，也不能覆盖第一条已经成立的间接移动证据。

## 间接移动证据

实现形式可用新增字段或局部 helper，但语义必须满足以下条件：

1. B/C 是 operation-start 的旧库存，且有自己的直接检测框和唯一归属。
2. B/C 的观测位置相对自身原位置发生连续变化，或最终位置连续稳定；不能借用 A 的
   检测框、手框位移或其他物品的框。
3. B/C 与直接活动的 A（或已确认的间接移动簇）存在合理的接触/推动关系，例如操作
   期间相邻且运动方向、时间顺序能够接上。B/C 不要求被手覆盖。
4. 无手阶段仍须使用连续直接帧确认最终框；复用既有的无手确认帧数，不新增全局魔法数。
5. 同类物品必须使用全局一对一分配和连续轨迹。一个框能合理属于多个旧物品时，不得
   用它确认其中任何一个间接移动物品。

间接移动只扩展“旧 C 如何结算”，不得改变 D 的创建、提升、隔离和最终 IN 规则。

## 实现边界

- 检查 `process_effective_hand_frame_()` 中旧 C 建轨/更新逻辑：允许可见但未被手覆盖的
  B/C 成为可撤销的间接移动候选，不能直接把它们设为 HAND_* 或复制手的位移。
- 在无手结算中，先保留当前已有的静态旧 C 与 C-D alias 仲裁；随后处理已具备独立
  间接移动证据的 B/C；最后才走稳定观察重同步。
- 修改 `try_release_stable_near_original_no_hand_()` 或相邻收尾点时，不能让细节14的
  静态灰区把已具备间接移动证据的 B/C 错误释放为 STATIC。
- 只有确认“位置发生更新”的旧物品才更新 `base_box`；普通单帧检测抖动不得污染库存
  基准框。
- 日志应明确记录：`INDIRECT-MOVE` / `STABLE-REBASE` / `UNRESOLVED`，以及唯一归属、
  连续帧、接触关系、原始框和最终框，便于实机复核。

## 同类物品的限制

不同类物品可按类别和连续轨迹关联。多个同类物品最终仍能得到多个独立框时，必须全局
一对一匹配，再分别结算。

若多个同类物品长期贴住，YOLO 只输出一个合并框，则仅凭 `cls_id + BBox` 无法可靠得知
哪个 item_id 对应哪个实体。此时正确行为是保持未决并等待后续分开；绝不能为了避免卡住
而误报 MOVED、OUT 或 IN。未来若必须覆盖这种信息不足的极端情况，需要实例分割或外观
特征等额外视觉信息，不属于本次状态机补丁范围。

## 必须新增的回归测试

1. A 直接移动并带动可见、不同类 B；B 未被手覆盖，最终 B 位移超过 28px：A、B 都正确
   更新，操作提交，没有 IN/OUT。
2. 同场景但 B 位移小于 28px：B 的 `base_box` 正确更新，不产生伪 MOVED、IN 或 OUT。
3. 密集摆放下 B 实际未移动，但其唯一直接检测框连续稳定地偏离旧框：允许稳定重同步并
   提交，不产生 B 的 MOVED。
4. A 推动多个可分别检测的旧物品：每个唯一可确认的物品正确更新。
5. 两个同类 B/C 都可分别检测：全局一对一身份不交换。
6. 两个同类物品只剩一个合并框：保持未决，不产生错误库存事件。
7. 保留并运行全部既有 `session3_replay_test`，特别是正常 IN/OUT/MOVED、同类邻居、
   C-D alias、细节13/14相关用例。

## 验收标准

真实的间接位移不再因“没有直接手持证据”卡住；身份唯一的稳定检测框偏移也不再造成
永久未决。只有确实无法区分身份的合并框才保守保持未决。与此同时，现有正常操作、
同类歧义保守策略和假 D 防线必须全部保持通过。

本次原则上不新增或修改超参数；只有实现确实新增 `constexpr` 时，才同步更新
`超参数位置与调节说明.txt`。
