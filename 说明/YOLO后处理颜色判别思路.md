# YOLO后处理颜色判别思路

这份说明只记录“后处理二次判别”的思路，不修改 YOLO 模型本身。

核心原则：先相信 YOLO，再用颜色和几何特征修正少量容易混淆的结果。

## 触发条件

- 只对少数容易混淆的类别对生效：`apple / onion`、`egg / orange`
- 只在 YOLO 的 top-1 与 top-2 分数很接近时触发
- 如果 YOLO 本身已经很确定，就不做人工修正

## 判别顺序

1. 读取 YOLO 输出的类别、置信度和框位置
2. 先看是否落在需要二次判别的类别对里
3. 截取 bbox 中心区域，不用整框平均，尽量减少背景干扰
4. 提取颜色特征，优先看 HSV / Lab，而不是直接看 RGB
5. 再结合框面积、长宽比、圆度做辅助判断
6. 输出最终类别时，保留 YOLO 分数作为基础，再叠加手动规则

## 苹果 / 洋葱

- 洋葱如果偏紫、偏暗、亮度低，倾向判为洋葱
- 苹果如果更红、更亮、颜色更鲜，倾向判为苹果
- 如果颜色特征不明显，优先保留 YOLO 原结果

## 鸡蛋 / 橙子

- 鸡蛋通常偏黄白、饱和度低、框面积偏小
- 橙子通常更偏橙红、饱和度更高、框面积偏大
- 如果颜色接近，再用面积和长宽比辅助判断

## 注意点

- 这个方法只适合演示和短期修正，不是通用分类方案
- 规则要尽量保守，宁可不改，也不要大范围覆盖 YOLO 的原判断
- 后续如果要继续优化，优先从真实场景照片里调阈值，而不是先改模型结构
