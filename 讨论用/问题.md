我稍微想了想：
    其实我不需要使用 "成熟期" 这个概念吧
    一个物品在刚刚变成 CONTACT_* / HAND_* 的这一帧时, 他本身就不会去于其他框进行匹配
    他是发现他于手的关系特别近的手，并且符合变成 CONTACT_* / HAND_* 时就变的, 这个过程中他没有去跟其他框进行匹配, 并且没有去挣吧
    等到下一帧, 他们才回去算出一个当前帧的估计框的位置，然后看原先位置是否又能看会自己, 并且看看估计框是否能匹配到一个未匹配的B, 如果原先位置看不到自己并且又能匹配到B他们才认为他们是同一个物品, 并且移动到B的位置(相应计数器加1 ) 如果 hold_evidence_count >= 2 就该对应变量为 True, 这个变量变成True之后, 后续只是不需要再去原位置匹配是否看得见自己而已，其他的其实跟原先都是照样执行的(估计框也要算, 并且看看估计框是否能匹配到一个未匹配的B, 这些全都是跟之前是一样的操作啊)
    当not_hold_evidence_count >= 2的时候，这个物品就变回原先的状态, 不再是 CONTACT_* / HAND_* 


也就是说：
    这个过程中, 其实并没有什么挣的地方吧？我们是不是不需要使用"成熟期"这种方法？
