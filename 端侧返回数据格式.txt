入库示例

  {
    "device_id": "luckfox-pico-01",
    "timestamp": 1781488800000,
    "event_type": "ITEM_IN",
    "data": [
      {
        "local_track_id": 101,
        "category": "苹果",
        "confidence": 0.91,
        "bbox": [88, 120, 140, 132],
        "crop_image": "/9j/4AAQSkZJRgABAQ..."
      }
    ]
  }

  入库时 crop_image 强烈建议带上，因为后端会用它做云端复核、图片保存、去重。

  出库示例

  {
    "device_id": "luckfox-pico-01",
    "timestamp": 1781488860000,
    "event_type": "ITEM_OUT",
    "data": [
      {
        "local_track_id": 101,
        "category": "苹果",
        "confidence": 0.88,
        "bbox": [90, 118, 138, 130],
        "crop_image": "/9j/4AAQSkZJRgABAQ..."
      }
    ]
  }

  当前后端出库主要按 device_id + category 找库存，所以 category 要尽量准确。crop_image 可选，但联调期建议带，方便排查。

  整理 / 移动示例

  整理货架、物体位置变化，可以发 ITEM_MOVED：

  {
    "device_id": "luckfox-pico-01",
    "timestamp": 1781488920000,
    "event_type": "ITEM_MOVED",
    "data": [
      {
        "local_track_id": 101,
        "category": "苹果",
        "confidence": 0.93,
        "bbox": [220, 100, 142, 136],
        "crop_image": ""
      }
    ]
  }

  整理事件主要更新位置，所以关键是 local_track_id / category / bbox。

  后端成功返回一般是库存记录数组，例如：

  [
    {
      "id": "b3f0b4f2-8a4e-4b5e-9e1c-xxxx",
      "device_id": "luckfox-pico-01",
      "category": "苹果",
      "status": "IN_STOCK",
      "remain_ratio": 1.0,
      "bbox": [88, 120, 140, 132],
      "snapshot_path": "uploads/luckfox-pico-01_101_1781488800.jpg",
      "created_at": "2026-06-15T10:00:00"
    }
  ]
