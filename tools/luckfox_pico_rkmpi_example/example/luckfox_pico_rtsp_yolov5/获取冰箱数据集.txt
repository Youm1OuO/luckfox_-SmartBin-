# 获取冰箱数据集 — 怎么做

## 你需要做的事情

```
第 1 步：临时关掉主程序的画框功能，在 Docker 里重新编译（只需一次）
第 2 步：在 WSL 里对着冰箱拍照片

第 5 步：在 WSL 里转换标注格式 + 训练模型
第 6 步：恢复画框功能，重新编译
```

## 第 2 步：拍照片

### 2.1 在 LuckFox 上启动主程序

1. 登录你的 LuckFox
2. 输入：
   ```bash
   ./luckfox_pico_rtsp_yolov5 model/yolov5.rknn
   ```
3. 看到 success 就成功了，不要关掉窗口

### 2.2 在 WSL 里装 ffmpeg（只需装一次，装过就跳过）

```bash
sudo apt install ffmpeg -y
```

### 2.3 在 WSL 里拍照

```bash
cd ~/Projects/workspace/luckfox_demo/tools/luckfox_pico_rkmpi_example/example/luckfox_pico_rtsp_yolov5
mkdir -p dataset_raw
ffmpeg -i rtsp://192.168.168.100:554/live/0 -vf "fps=2" -q:v 2 dataset_raw/batch1_%04d.jpg -v quiet -stats
```

> 说明：
> - 192.168.168.100 → 改成你 LuckFox 的实际 IP
> - 554 → RTSP 端口，不用改
> - fps=2 → 每秒截 2 张
> - 拍够了按 Ctrl+C 停止

照片直接保存在 WSL 里，不需要手动传。

### 2.4 拍的时候你要做的事

- 把苹果、可乐、牛奶盒等你要识别的东西，一个个放进冰箱
- 每个东西换 3~5 个位置/角度放
- 也拍几张手拿东西的画面
- 拍够了按 Ctrl+C 停止

### 2.5 想拍很多照片？多跑几次就行

每次把 batch1 改成 batch2、batch3...：
```bash
ffmpeg -i rtsp://192.168.168.100:554/live/0 -vf "fps=2" -q:v 2 dataset_raw/batch2_%04d.jpg -v quiet -stats
```

### 2.6 看看拍了多少张

```bash
ls dataset_raw/*.jpg | wc -l
```



### 4.3 labelme 操作方法

1. 画框：       按 Ctrl+R → 拖鼠标画框框住一个东西
2. 输入类别：   弹出输入框，输入类别名（比如 apple）→ 点 OK
3. 保存：       按 Ctrl+S
4. 下一张：     按键盘 →（右方向键）
5. 重复，直到标完所有照片



### 4.4 你的冰箱要识别的东西（共 43 种）

输入类别名称时，必须用下面这些英文名（大小写要一致）：

水果类：apple、banana、orange、tomato、lemon、pear、grape、strawberry、watermelon、cantaloupe、papaya、avocado

蔬菜类：cucumber、carrot、potato、onion、bell_pepper、leafy_green、mushroom、pumpkin、garlic、ginger、radish、sweet_potato、coriander、okra

肉蛋类：egg、meat_pack、fish_pack

饮料类：milk_box、milk_bottle、yogurt_cup、juice_bottle、soda_can、water_bottle

包装食品：bagged_food、boxed_food、canned_food、jar_food、plastic_wrap、fresh_box

手：hand（这个必须标！系统靠它判断你有没有在动冰箱里的东西）

> 每种东西至少标 100 张，效果才好。

## 第 5 步：转换标注格式 + 训练模型

### 5.1 转换标注格式

labelme 保存的是 JSON 格式，需要转成 YOLO 格式才能训练。

在 WSL 里运行：
```bash
cd ~/Projects/workspace/luckfox_demo/tools/luckfox_pico_rkmpi_example/example/luckfox_pico_rtsp_yolov5
python3 tools/convert_labels.py
```

它会自动：
- 把 JSON 文件从 images/ 目录移到 labels/ 目录
- 把 JSON 转成 YOLO 格式的 .txt 文件







### 5.2 下载 YOLOv5（只需下一次）

```bash
git clone https://github.com/ultralytics/yolov5.git
cd yolov5
pip install -r requirements.txt
cd ..
```

### 5.3 开始训练

```bash
python3 yolov5/train.py --data dataset/data.yaml --weights yolov5/yolov5s.pt --epochs 100 --batch-size 16 --img 704 --name fridge_model
```

训练需要几个小时，训练完后新模型在：
```
yolov5/runs/train/fridge_model/weights/best.pt
```

然后还需要转成 .rknn 格式，等你训练完再告诉我，我帮你弄。

## 附：检查标注对不对

```bash
python3 -c "
import cv2, glob, os
for img in sorted(glob.glob('dataset/images/train/*.jpg'))[:20]:
    lbl = img.replace('/images/', '/labels/').replace('.jpg', '.txt')
    im = cv2.imread(img)
    h, w = im.shape[:2]
    if os.path.exists(lbl):
        for line in open(lbl):
            c, cx, cy, bw, bh = line.split()
            x1 = int((float(cx)-float(bw)/2)*w)
            y1 = int((float(cy)-float(bh)/2)*h)
            x2 = int((float(cx)+float(bw)/2)*w)
            y2 = int((float(cy)+float(bh)/2)*h)
            cv2.rectangle(im,(x1,y1),(x2,y2),(0,255,0),2)
            cv2.putText(im, c, (x1,y1-5), cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0,255,0), 2)
    cv2.imshow('check (press any key)', im)
    cv2.waitKey(0)
"
```
