# 矩形 A 的动态遮挡与剩余区域维护

## 1. 任务背景

当前有一个初始矩形 **A**。之后会按照顺序不断加入新的矩形，例如 **B、C、D、E……**。
这些后加入的矩形可以理解为“遮挡矩形”：当它们覆盖到 A 当前仍然可见的区域时，被覆盖的部分需要从 A 的可见区域中删除。
我们关心的不是每个新矩形是否与**原始矩形 A**相交，而是它是否与 **A 在当前时刻尚未被遮挡的区域**相交。

---

## 2. 要解决的问题

需要设计一种数据表示和处理方法，完成以下任务：

1. 初始时，A 的全部区域都可见。
2. 矩形 B 进入后，判断 B 是否真正遮挡了 A。
3. 如果 B 与 A 的当前可见区域有交集，则从当前可见区域中扣除 B 覆盖的部分。
4. 如果后续矩形 C 与 A 当前剩余区域没有交集，则 C 不产生任何影响，当前状态保持不变。
5. 如果后续矩形 D 与 A 当前剩余区域有交集，则继续从剩余区域中扣除 D 覆盖的部分。
6. 对之后到来的任意矩形重复同样的处理。
7. 在任意时刻，都能够得到 A 当前还剩下哪些可见区域。

整个过程可以抽象为：
- 初始状态：A
- B 有效遮挡后：A − B
- C 没有遮挡当前剩余区域：仍然是 A − B
- D 有效遮挡后：(A − B) − D
- 后续矩形继续依次从当前剩余区域中扣除

这里的“减法”不是数值减法，而是几何意义上的**区域差集**。

---

## 3. 问题的关键点

### 3.1 判断对象不是原始 A

处理新矩形时，不能始终拿它与原始 A 比较。

例如：
- B 已经覆盖了 A 中间的一块区域；
- C 完全落在 B 已经覆盖过的范围内；
- 虽然 C 与原始 A 相交，但 C 与 A 当前仍然可见的区域没有交集。

因此，C 不应该再次修改结果，也不应该被认为产生了新的有效遮挡。

正确的判断对象应当是：
> [新矩形]是否与[A当前剩余可见区域]相交。

---

### 3.2 A − B 通常不再是一个矩形

如果 B 只遮挡 A 的一角，A − B 可能呈现“L”形。
如果 B 位于 A 中间，A − B 可能由上、下、左、右多个彼此分离或相邻的区域组成。
因此，经过第一次遮挡之后，不能再只用一个普通矩形表示 A 的剩余区域。
需要把 A 的当前剩余区域表示为：
- 多个互不重叠的矩形块；或者(or)
- 一个通用的二维多边形区域；或者(or)
- 一个支持布尔运算的几何区域对象。

在所有矩形都与坐标轴平行的情况下，使用“多个矩形块的集合”通常最容易实现。

---

### 3.3 新矩形只处理当前仍然存在的区域

假设当前 A 的剩余区域已经被拆成若干矩形块。

当新矩形进入时，需要**逐块检查**：
- 与新矩形没有交集的剩余块，原样保留；
- 与新矩形有交集的剩余块，扣除交集部分；
- 一个剩余块扣除新矩形后，可能被拆成零到四个新的矩形块；
- 所有处理结果共同组成下一时刻的剩余区域。

如果新矩形与所有剩余块都没有交集，则说明它没有遮挡 A 当前可见部分，整个状态保持不变。

---

## 4. 核心解决思路

### 4.1 维护一个“当前剩余区域”

系统始终保存一个状态，表示 A 当前还没有被遮挡的所有区域。
初始时，这个状态只包含完整的 A。
每加入一个新矩形，都基于当前状态计算下一状态，而不是重新从原始 A 开始计算。

可以把这个状态理解为：
> A 当前可见区域的矩形块集合。

---

### 4.2 对新矩形进行有效性判断

新矩形进入后，检查它是否与当前剩余区域中的至少一个矩形块存在正面积交集。

需要区分：
- 仅边界接触：通常不认为产生遮挡；
- 仅一个点接触：不认为产生遮挡；
- 存在正宽度且正高度的重叠区域：认为产生遮挡。

如果不存在有效交集，新矩形被忽略，当前剩余区域不变。
如果存在有效交集，则执行区域扣除，并更新当前剩余区域。

---

### 4.3 只对相交的剩余块做差集

对于当前剩余区域中的每一个矩形块：
- 如果它与新矩形不相交，直接保留；
- 如果它与新矩形相交，则从该矩形块中移除交集区域；
- 剩余部分根据几何位置拆分成若干更小的矩形块。

这样处理完成后，得到的所有矩形块之和，就是新的 A 剩余可见区域。

---

### 4.4 保持一个重要的不变量

整个算法应始终保证：
> 当前保存的所有矩形块互不重叠，并且它们的并集恰好等于 A 尚未被有效遮挡的区域。

只要这个条件在每次更新后都成立，就可以继续正确处理后续任意数量的矩形。

---


## 5. 示例过程

假设：

- A 是初始矩形；
- B 遮挡了 A 中的一部分；
- C 完全落在 B 已经遮挡的区域中；
- D 又遮挡了 A 当前仍然可见的一部分。

处理过程如下。

### 第一步：初始化

A 当前剩余区域就是完整的 A。

### 第二步：加入 B

检查 B 与 A 当前剩余区域是否相交。
如果相交，则从 A 中扣除 B 覆盖到的部分，当前状态变成 A − B。

### 第三步：加入 C

检查 C 与 A − B 是否相交。
虽然 C 可能与原始 A 相交，但如果 C 完全位于已经被 B 删除的区域中，那么 C 与当前剩余区域没有交集。
因此，C 不产生影响，状态仍然是 A − B。

### 第四步：加入 D

检查 D 与 A − B 是否相交。
如果 D 覆盖了当前仍然可见的部分，则继续扣除，状态变成：(A − B) − D
之后的矩形继续按照同样方式处理。

---

## 6. 推荐的数据表示

如果满足以下条件：
- 所有矩形都与坐标轴平行；
- 坐标使用整数或普通浮点数；
- 只需要表示遮挡后的可见区域；

推荐使用：
> 一个由多个互不重叠矩形块组成的集合。

每个矩形块保存四个边界坐标，例如：
- 左边界；
- 上边界；
- 右边界；
- 下边界。

整个集合表示 A 当前还可见的区域。
如果矩形允许旋转，或者后续图形不再局限于矩形，则更适合使用通用的多边形裁剪或几何布尔运算库。

---

## 7. 需要注意的问题

### 7.1 矩形碎片数量可能增加

一个矩形块被遮挡后，最多可能拆成四个新的矩形块。

随着遮挡矩形不断增加，剩余区域可能变得越来越碎，矩形块数量也可能增长。

实际实现时，可以考虑：

- 删除面积为零的矩形块；
- 合并可以无缝拼接的相邻矩形块；
- 对矩形块做规范化排序；
- 根据业务规模评估是否需要更高效的空间索引。

---

### 7.2 坐标边界定义要统一

需要明确矩形坐标的含义，例如：

- 左闭右开；
- 全闭区间；
- 连续几何坐标。

在图像像素坐标中，通常建议使用左闭右开、上闭下开的范围表示方式，这样可以减少边界重复和宽高计算错误。

---

### 7.3 浮点数误差

如果坐标是浮点数，判断两个边界是否相等时可能出现精度问题。

需要根据实际坐标范围设置一个合理的误差阈值，避免产生非常窄、实际上应当为零的矩形碎片。

---

### 7.4 “是否遮挡”需要明确定义

通常建议把“有效遮挡”定义为：

> 新矩形与当前剩余区域的交集面积大于零。

只有边或顶点接触时，不认为产生遮挡。

如果业务中边界接触也有特殊意义，则需要单独定义相交规则。

---

## 8. 最终目标

实现完成后，系统应支持以下能力：

- 顺序接收任意数量的新矩形；
- 判断每个新矩形是否真正遮挡了 A 当前可见区域；
- 忽略没有产生新遮挡的矩形；
- 实时更新 A 的剩余可见区域；
- 在任意时刻输出 A 当前剩余的所有区域；
- 可选地计算 A 当前剩余面积、已遮挡面积和遮挡比例。

这个任务本质上是一个：

> 对固定初始区域 A，按照输入顺序持续执行二维矩形差集，并动态维护差集结果的问题。

# 数据类型表示
> [单个矩形]使用 xyxy 格式表示： 
    Box = [x1, y1, x2, y2]
其中：
    (x1, y1) 表示左上角坐标
    (x2, y2) 表示右下角坐标
并且要求：
    x1 < x2
    y1 < y2

> 而 A-B 往往不再是一个矩形, 所以[A当前剩余区域]要表示成：
    Region = list[Box]

需要始终维持这个不变量：
1. Region 中所有矩形的并集, 等于 A 当前没有被遮挡的区域
2. 并且这些矩形块之间不重叠



# 完整代码实现
```python
"""
轴对齐矩形的动态遮挡计算
矩形统一使用 xyxy 格式：box = [x1, y1, x2, y2]
其中：
    (x1, y1) 是左上角
    (x2, y2) 是右下角
要求：
    x1 < x2
    y1 < y2
"""

from typing import Sequence, TypeAlias

Number: TypeAlias = int | float

# 单个矩形：[x1, y1, x2, y2]
Box: TypeAlias = list[Number]

# A 当前的剩余区域，由多个互不重叠的矩形块组成
Region: TypeAlias = list[Box]


# 创建并检查一个 xyxy 矩形
def make_box(
    x1: Number,
    y1: Number,
    x2: Number,
    y2: Number,
) -> Box:
    """
    创建并检查一个 xyxy 矩形
    """
    if x1 >= x2:
        raise ValueError(f"x1 必须小于 x2, 当前坐标：[{x1}, {y1}, {x2}, {y2}]")
    if y1 >= y2:
        raise ValueError(f"y1 必须小于 y2, 当前坐标：[{x1}, {y1}, {x2}, {y2}]")

    return [x1, y1, x2, y2]


# 将 list、tuple、Tensor.tolist() 等形式统一转换成 Box 的形式
def normalize_box(box: Sequence[Number]) -> Box:
    """
    将 list、tuple、Tensor.tolist() 等形式统一转换成 Box 的形式
    例如：[1, 2, 3, 4]、(1, 2, 3, 4)都可以作为输入
    """
    if len(box) != 4:
        raise ValueError(f"矩形必须包含 4 个值 [x1, y1, x2, y2], 当前为：{box}")
    x1, y1, x2, y2 = box

    return make_box(x1, y1, x2, y2)


# 计算单个矩形的面积
def box_area(box: Sequence[Number]) -> Number:
    """
    计算单个矩形的面积
    """
    x1, y1, x2, y2 = box
    return (x2 - x1) * (y2 - y1)


# 计算两个矩形的交集
def get_intersection(
    first: Sequence[Number],
    second: Sequence[Number],
) -> Box | None:
    """
    计算两个矩形的交集

    若返回 [x1, y1, x2, y2]： 说明存在面积大于 0 的交集
    若返回 None：说明没有交集, 或者仅边缘接触
    """
    first_x1, first_y1, first_x2, first_y2 = first
    second_x1, second_y1, second_x2, second_y2 = second

    intersection_x1 = max(first_x1, second_x1)
    intersection_y1 = max(first_y1, second_y1)
    intersection_x2 = min(first_x2, second_x2)
    intersection_y2 = min(first_y2, second_y2)

    # 没有面积交集。
    # 等号表示仅边缘接触，也不算覆盖。
    if (intersection_x1 >= intersection_x2 or intersection_y1 >= intersection_y2):
        return None

    return [
        intersection_x1,
        intersection_y1,
        intersection_x2,
        intersection_y2,
    ]


# 如果坐标可以构成面积大于 0 的矩形, 就加入结果
def append_box_if_valid(
    result: Region,
    x1: Number,
    y1: Number,
    x2: Number,
    y2: Number,
) -> None:
    """
    如果坐标可以构成面积大于 0 的矩形, 就加入结果
    """
    if x1 < x2 and y1 < y2:
        result.append([x1, y1, x2, y2])


# 将 source - overlap 之后的结果拆成若干个矩形块 (最多拆成 4 个矩形块)
def split_remaining_parts(
    source: Sequence[Number],
    overlap: Sequence[Number],
) -> Region:
    """
    将 source - overlap 之后的结果拆成若干个矩形块 (最多拆成 4 个矩形块)
    且返回的矩形块互不重叠

    示意：
        +-----------------------+
        |         上方           |
        +------+---------+------+
        | 左方 | overlap | 右方 |
        +------+---------+------+
        |         下方           |
        +-----------------------+
    """
    source_x1, source_y1, source_x2, source_y2 = source
    overlap_x1, overlap_y1, overlap_x2, overlap_y2 = overlap

    result: Region = []

    # 上方区域
    append_box_if_valid(
        result,
        source_x1,
        source_y1,
        source_x2,
        overlap_y1,
    )

    # 下方区域
    append_box_if_valid(
        result,
        source_x1,
        overlap_y2,
        source_x2,
        source_y2,
    )

    # 左方区域
    append_box_if_valid(
        result,
        source_x1,
        overlap_y1,
        overlap_x1,
        overlap_y2,
    )

    # 右方区域
    append_box_if_valid(
        result,
        overlap_x2,
        overlap_y1,
        source_x2,
        overlap_y2,
    )

    return result


# 从单个 source 矩形中减去 cover
def subtract_box(
    source: Sequence[Number],
    cover: Sequence[Number],
) -> tuple[Region, bool]:
    """
    从单个 source 矩形中减去 cover。

    返回：
        remaining_parts：source 被覆盖后剩余的矩形块
        covered：cover 是否实际覆盖了 source 的部分面积

    情况：
        若 source 与 cover 无交集：[source], False
        若 source 被 cover 完全覆盖：[], True
        若 source 被 cover 部分覆盖：1～4 个矩形块, True
    """
    # 计算两个矩形的交集
    overlap = get_intersection(source, cover)

    # 若无交集
    if overlap is None:
        return [list(source)], False

    # 有交集
    remaining_parts = split_remaining_parts(source=source, overlap=overlap)
    return remaining_parts, True


# 从 A 当前整个剩余区域中减去 new_cover
def apply_cover(
    remaining: Region,
    new_cover: Sequence[Number],
) -> tuple[Region, bool]:
    """
    从 A 当前整个剩余区域中减去 cover。
    (A可能已经分成了多个source)

    返回：
        new_region：处理后, A 新的剩余区域
        covered：new_cover 是否覆盖了 A 当前剩余区域的任何部分
    """
    # 转换成 Box 的形式(以防万一, 健壮性)
    normalized_cover = normalize_box(new_cover)

    new_region: Region = []     # 要用一个新的变量保存结果, 不能在原来的基础上增加(因为会重复)
    covered = False

    # A可能已经分成了多个source, 因此需要遍历
    for part in remaining:
        remaining_parts, part_covered = subtract_box(source=part, cover=normalized_cover)
        new_region.extend(remaining_parts)   # 追加到新的剩余区域
        if part_covered:
            covered = True     # 只要有一个区域被覆盖, 就返回True

    return new_region, covered


# 计算 A 当前剩余区域的总面积
def region_area(region: Region) -> Number:
    """
    计算 A 当前剩余区域的总面积
    """
    return sum(box_area(box) for box in region)


# 打印当前剩余区域
def print_region(
    title: str,
    region: Region,
) -> None:
    """
    打印当前剩余区域。
    """
    print(
        f"\n{title} | "
        f"矩形块数量={len(region)} | "
        f"总面积={region_area(region)}"
    )

    if not region:
        print("A 已被完全覆盖")
        return

    for index, box in enumerate(region, start=1):
        print(f"  第 {index} 块：{box}，面积={box_area(box)}")


# -------------------------------------------------------------


if __name__ == "__main__":
    # 使用例子
    def main() -> None:
        # A 是最初的矩形
        A = normalize_box([0,0,10,10])
        
        # B 覆盖 A 中间的一部分
        B = normalize_box([2,2,6,6])

        # C 完全处于 B 已经覆盖过的范围内
        C = normalize_box([3,3,5,5])

        # D 一部分位于 B 内，一部分覆盖 A 当前剩余区域
        D = normalize_box([5,5,9,9])

        # 初始剩余区域就是完整的 A
        remaining: Region = [A]

        print_region("初始状态", remaining)
        remaining, b_covered = apply_cover(remaining=remaining, new_cover=B)

        print(f"\nB 是否覆盖 A 当前剩余区域：{b_covered}")
        print_region("处理 B 后", remaining)

        remaining, c_covered = apply_cover(remaining=remaining, new_cover=C)

        print(f"\nC 是否覆盖 A 当前剩余区域：{c_covered}")
        print_region("处理 C 后", remaining)

        remaining, d_covered = apply_cover(remaining=remaining, new_cover=D)

        print(f"\nD 是否覆盖 A 当前剩余区域：{d_covered}")
        print_region("处理 D 后", remaining)

        # 预期：
        # B 实际发生覆盖
        # C 只位于已经被 B 删除的区域内，没有新增覆盖
        # D 实际发生覆盖
        assert b_covered is True
        assert c_covered is False
        assert d_covered is True

        # A 面积 100
        # B 新增覆盖 16
        # C 新增覆盖 0
        # D 新增覆盖 15
        assert region_area(remaining) == 69

        print("\n所有断言验证通过")

    main()
```
